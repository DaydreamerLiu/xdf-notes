一、导论: 马克思主义是什么

1.1 马克思主义的创立

必考 导论每年约1道选择题(1分), 考察方式为原文型/立场型。

马克思主义产生于19世纪40年代。其创立有三个条件:

维度 内容
社会根源 资本主义基本矛盾的激化与发展, 预示了未来社会变革的性质和历史发展的方向
阶级基础 无产阶级作为独立政治力量登上历史舞台(三大工人运动)
思想渊源 德国古典哲学、英国古典政治经济学、英法空想社会主义

为什么是这三大思想渊源? 逻辑上, 马克思主义三大组成部分(哲学、政治经济学、科学社会主义)分别对应三大来源: 从黑格尔/费尔巴哈的哲学中提炼唯物辩证法; 从斯密/李嘉图的劳动价值论中发展出剩余价值学说; 从圣西门/傅立叶/欧文的空想中确立科学的社会主义道路。

重点马克思、恩格斯重要著作:

  • 《共产党宣言》(1848): 第一个无产阶级政党纲领, 标志马克思主义公开问世
  • 《德意志意识形态》: 首次系统阐述历史唯物主义基本观点
  • 《反杜林论》: 恩格斯全面阐述马克思主义理论体系(哲学+政治经济学+科学社会主义)
  • 《资本论》: 剩余价值理论的完整阐述

注意辨析:

  • 世界上第一个无产阶级政党: 共产主义者同盟(1847年, 前身正义者同盟)
  • 社会主义从空想变为科学的两大发现: 唯物史观 + 剩余价值学说

1.2 马克思主义的基本特征

高频 马克思主义的六个基本特征:

  • 科学性: 对自然、社会和人类思维发展本质和规律的正确反映
  • 人民性: 人民至上是马克思主义的政治立场
  • 实践性: 从实践中来、到实践中去、在实践中接受检验并随实践发展 -- 区别于其他理论的显著特征
  • 发展性: 与时俱进的理论品质
  • 开放性: 不断吸收人类优秀思想文化成果
  • 革命性: 彻底的批判精神和鲜明的无产阶级立场

概括: 马克思主义 = 科学性与革命性的统一。实践性是区别于其他理论的显著特征(习近平: "马克思主义不是书斋里的学问")。

二、哲学总论: 世界观与方法论

2.1 哲学基本问题

必考 恩格斯: "全部哲学, 特别是近代哲学的重大的基本问题, 是思维和存在的关系问题。"

哲学基本问题包含两个层面:

第一性(本体论)问题 — 思维与存在何者为第一性? → 唯物主义(物质第一性) vs 唯心主义(意识第一性)

同一性(认识论)问题 — 思维与存在是否具有同一性? → 可知论(可以被认识) vs 不可知论(不能/不能完全被认识)

为什么哲学基本问题不是"世界统一于什么"? 因为"存在"既包含物质存在也包含精神存在。"世界统一于存在"是折中主义二元论的错误说法 -- 正确的说法是"世界统一于物质"。

易错四个派系的对立:

区分维度 派系A 派系B
第一性 唯物主义 唯心主义
同一性 可知论 不可知论
发展观 辩证法(联系/发展/全面/承认内部矛盾) 形而上学(孤立/静止/片面/否认内部矛盾)
历史观 唯物史观(社会存在决定社会意识) 唯心史观(社会意识决定社会存在)

2.2 唯物主义的三形态

易错三种唯物主义形态比较:

形态 物质观 局限性
古代朴素唯物主义 物质 = 具体实物(水、火、气等) 直观性/朴素性
近代形而上学唯物主义 物质 = 原子(微观结构) 机械性/形而上学性; 混淆自然科学物质概念与哲学物质概念
现代辩证唯物主义 物质 = 客观实在(从哲学上最高概括) 无

关键理解: 旧唯物主义(古代+近代)都是"半截子唯物主义"——自然观唯物, 但历史观唯心。只有现代辩证唯物主义是彻底的唯物主义, 自然观与历史观均唯物。

2.3 唯心主义的两种形态

形态 核心观点 代表人物及命题
主观唯心主义 人的主观精神(感觉/意志/心灵)是世界的本原 "我思故我在"(笛卡尔) / "存在就是被感知"(贝克莱) / "心外无物"(王阳明)
客观唯心主义 客观精神(上帝/理念/绝对精神)是世界的本原 "理在事先"(朱熹) / "现实世界是观念世界的影子"(柏拉图)

三、唯物论: 物质与意识

3.1 物质观

重点 马克思主义对"物质"的界定:

  • 恩格斯(从共性与个性角度): "物、物质无非是各种物的总和, 而这个概念就是从这一总和中抽象出来的。" —— 物质的哲学范畴与具体物质是共性与个性的关系
  • 列宁(从物质与意识的关系角度): "物质是标志客观实在的哲学范畴, 这种客观实在是人通过感觉感知的, 它不依赖于我们的感觉而存在, 为我们的感觉所复写、摄影、反映。"

物质的唯一特性: 客观实在性。

物质观的理论意义: ①坚持了唯物主义一元论, 与唯心主义和二元论划清界限; ②坚持了能动的反映论和可知论, 批判了不可知论; ③体现了唯物论和辩证法的统一, 克服了形而上学的缺陷; ④体现了唯物主义自然观和历史观的统一, 为彻底的唯物主义奠定了理论基础。

3.2 运动观

必考物质与运动的关系:

  1. 运动是物质的存在方式和根本属性 --- "只要是物质, 一定是运动的"(错误观点: 形而上学)
  2. 物质是一切运动变化和发展过程的实在基础和承担者 --- "只要是运动, 一定有物质载体"(错误观点: 唯心主义)

运动与静止的关系:

运动 静止
特性 绝对性、无条件性 相对性、有条件性
关系 "动中有静, 静中有动" 静止是运动的特殊状态

静止的含义: ①空间相对位置暂时不变; ②事物根本性质暂时不变。

静止的意义: ①过去运动的结果和未来运动的出发点; ②物质运动的衡量尺度; ③认识事物的前提和条件。

易错常见判断:

  • "静者静动, 非不动也" ✅ (承认绝对运动)
  • "人不能两次踏进同一条河流" ✅ (承认绝对运动, 同时承认相对静止)
  • "人一次也不能踏进同一条河流" ❌ (相对主义诡辩论, 只承认运动否认静止)
  • "飞矢不动" / "天不变, 道亦不变" ❌ (形而上学不变论, 夸大静止否认运动)
  • "静止是运动的衡量尺度" ✅
  • "动是静的原因, 静是动的结果" ❌ (二者不是因果关系)

3.3 时空观

必考时间与空间:

  • 时间: 一维性(不可逆, "一去不复返")
  • 空间: 三维性(可逆, 长宽高/上下前后左右)
  • 注意: "时间"和"空间"表述不可通用/相互替换

时空与物质运动的关系: 时空是物质运动的存在形式, 二者不可分割 —— 没有离开物质运动的"纯粹"时空, 也没有离开时空的物质运动。

时空的特性:

  1. 客观性: 物质运动与时空的不可分割证明了时空的客观性
  2. 有限性与无限性的统一: 具体物质形态的时空是有限的, 整个物质世界的时空是无限的
  3. 易错: "时空是有限的" ❌ / "时空是无限的" ❌ / "时空具有有限性" ✅ / "时空具有无限性" ✅

3.4 意识观

必考意识的起源:

  1. 自然界长期发展的产物(三阶段: 反应特性 → 刺激感应性 → 感觉和心理 → 人的意识)
  2. 社会历史的产物: 劳动在意识产生和发展中起决定性作用, 语言促进了意识的发展

必考意识的本质:

意识是客观世界的主观映象, 是客观内容和主观形式的统一。

  • 意识是特殊的物质——人脑的机能和属性
  • 意识在内容上是客观的, 在形式上是主观的
  • 意识是物质的产物, 但又不是物质本身

易错高频判断项:

  • "人脑是意识的源泉" ❌ (源泉是客观世界, 人脑是加工器官)
  • "人脑是意识产生的物质前提" ✅
  • "鬼神的观念是人脑对客观世界歪曲虚幻的反映" ✅
  • "鬼神观念是对事物本质的反映" ❌
  • "鬼神观念可以从现实世界找到物质原型" ✅ (任何意识都有客观原型)
  • "观念的东西不外是人脑中改造过的物质的东西而已" ✅ (马克思)
  • "语言是意识的物质外壳和直接现实" ✅

意识的能动作用(三性两指导):

  1. 目的性 -- 意识活动具有目的性和计划性
  2. 计划性 -- 在活动之前形成蓝图
  3. 创造性 -- 意识能够创造性地反映世界
  4. 指导实践改造客观世界
  5. 指导、控制人的行为和生理活动

意识与人工智能:

注意 人工智能不能取代/超越人类意识的原因:

  • 人类意识具有"知情意"(知识+情感+意志)的统一
  • 人类意识具有社会性
  • 人工智能不能完全理解自然语言的真实意义
  • 人脑中许多东西无法被化约为数字信号

但: "人工智能在一定程度上可以承担某种社会功能" ✅

3.5 主观能动性与客观规律性的辩证关系

【高频 · 分析题】

辩证关系原理: 第一, 尊重客观规律是发挥主观能动性的前提。第二, 只有充分发挥主观能动性, 才能正确认识和利用客观规律。第三, 实践是客观规律性与主观能动性统一的基础。

正确发挥主观能动性的前提和条件:

  1. 从实际出发, 是正确发挥主观能动性的前提
  2. 实践是正确发挥主观能动性的根本途径
  3. 主观能动性的发挥还依赖于一定的物质条件和物质手段

3.6 世界的物质统一性原理

世界物质统一性原理: ①世界是统一的, 即世界的本原是一个; ②世界的统一性在于它的物质性; ③物质世界的统一性是多样性的统一, 而不是单一的无差别的统一。

实践的作用: 实践是使物质世界分化为自然界和人类社会的历史前提, 又是使自然界和人类社会统一起来的现实基础。通过劳动, 人类具有了自己实践的存在方式。自在自然 → (实践活动) → 人化自然 / 人类社会。

四、辩证法: 联系与发展

4.1 两大总特征: 普遍联系与永恒发展

4.1.1 联系

必考联系的内涵: 事物内部各要素之间和事物之间相互影响、相互制约、相互作用的关系。

联系的特点:

特点 内容 判断项
客观性 事物的联系是事物本身所固有的 "主观联系" ❌
普遍性 任何事物都处于联系之中 "任何事物一定处在联系之中" ✅ / "任何事物一定和其他事物处于联系之中" ✅
多样性 直接/间接、内部/外部、必然/偶然、本质/非本质等 "城门失火殃及池鱼" = 间接联系
条件性 联系是有条件的 "任意两事物均能建立联系" ❌

4.1.2 发展

必考发展的实质: 新事物的产生和旧事物的灭亡。

新事物不可战胜的原因: ①适应环境变化; ②对旧事物"扬弃"(既克服又保留); ③符合人民群众利益和要求。

发展的过程性: "世界不是既成事物的集合体, 而是过程的集合体。"(恩格斯) —— 一切事物只有经过一定的过程才能实现自身的发展。

易错 "事物的发展总是呈现出线性上升的态势" ❌ —— 发展是前进性和曲折性的统一。

4.2 三大规律

4.2.1 对立统一规律(矛盾规律) 【超级重点】

必考 对立统一规律是唯物辩证法的实质和核心。它揭示了事物发展的动力和源泉。

为什么对立统一规律是核心? 因为它回答了事物"为什么发展"这个根本问题 —— 事物内部的矛盾(既对立又统一)是发展的根本动力。另外两大规律(量变质变、否定之否定)都是从不同角度补充说明"怎样发展"。

规律的特性: 客观联系(事物本身所固有)、本质联系(事物的共性)、必然联系(事物的发展方向)、稳定联系(重复性)。人与规律的关系: 不能藐视/创造/消灭/完善规律; 可以认识/发现/利用/改变规律发生作用的条件和形式。

重点自然规律与社会规律的区别:

自然规律 社会规律
实现方式 盲目、无意识的力量起作用 通过人的有意识的活动实现
表现形式 相同条件可完全相同地反复出现 不同社会/国家/民族/历史阶段有不同表现形式
联系 都具有不以人的意志为转移的客观性; 都是本质/必然/稳定的联系

矛盾的基本属性: 同一性与斗争性

同一性 斗争性
内涵 矛盾双方相互依存、相互贯通(一定条件下可以相互转化) 矛盾双方相互排斥、相互分离
特点 有条件性、相对性 无条件性、绝对性
作用 利用对方发展自己; 吸取有利因素; 向对立面转化发展 量变(力量对比变化); 质变(地位性质转化)

同一性与斗争性的辩证关系: 同一性不能脱离斗争性而存在, 斗争性也不能脱离同一性而存在。斗争性寓于同一性之中, 同一性通过斗争性来体现。两者结合构成事物的矛盾运动, 推动事物发展。

【注】对应分析题的原理表述:

  • "在危机中育新机、于变局中开新局" → 矛盾的同一性(矛盾双方在一定条件下相互转化) + 矛盾的普遍性与特殊性
  • "退路-出路" → 矛盾双方相互依存/贯通/转化(同一性) + 承认矛盾(普遍性) + 具体问题具体分析(特殊性)

矛盾的普遍性与特殊性(矛盾问题的精髓)

普遍性(共性) 特殊性(个性)
内涵 矛盾无处不在、无时不有(无条件、绝对) 处处矛盾不同、时时矛盾不同(有条件、相对)
关系 共性寓于个性之中, 在一定条件下共性与个性可以相互转化

方法论意义:

  • 普遍性 → 承认矛盾、分析矛盾、敢于揭露矛盾
  • 特殊性 → 具体问题具体分析, 用不同的方法解决不同的矛盾

矛盾的不平衡性原理

类型 区分依据 内容
根本矛盾 vs 非根本矛盾 是否贯穿事物发展过程始终 贯穿始终, 不能转化
主要矛盾 vs 次要矛盾 在矛盾体系中地位 支配vs从属, 可以转化
矛盾主要方面 vs 次要方面 在同一矛盾中地位 决定矛盾性质vs服从, 可以转化

方法论: 两点论与重点论的统一。 既要全面看问题(两点论), 又要抓住主要矛盾和矛盾的主要方面(重点论)。反对一点论和均衡论。

4.2.2 质量互变规律

必考揭示事物发展的形式和状态。

质、量、度:

概念 定义 意义
质 一事物成为自身并区别于他事物的内在规定性 认识和实践的起点和基础
量 存在和发展的规模、程度、速度等可以用数量表示的规定性 认识的深化和精确化
度 保持质的稳定性的数量界限(范围、幅度、限度) 提供"适度原则", 防止"过"或"不及"

量变与质变的辩证关系:

  1. 量变是质变的必要准备(没有量变积累, 质变不会发生)
  2. 质变是量变的必然结果(量变达到一定程度必然引起质变)
  3. 量变和质变相互渗透(总的量变中有部分质变; 质变中有量的扩张)

易错判断:

  • "量变一定引起质变" ❌ (缺条件: 达到一定程度)
  • "量变必然引起质变" ✅ ("必然"代表坚定不移的趋势)
  • 区分量变和质变的根本标志: 事物的变化是否超出度

4.2.3 否定之否定规律

必考揭示事物发展的方向和道路。

辩证否定观:

  • 否定是事物的自我否定(内部矛盾运动), 不是外部否定
  • 否定是事物发展的环节(没有否定就没有发展)
  • 否定是新旧事物联系的环节("扬弃"——既克服又保留)

发展过程: 肯定 → 否定 → 否定之否定(两次否定、三个阶段、一个周期)

前进性与曲折性的统一:

  • 前进性: 每一次否定都是质变, 都把事物推到新阶段
  • 曲折性: 发展呈现螺旋式上升或波浪式前进, 有暂时的停顿或倒退
  • 总趋势: 方向是前进上升的, 道路是迂回曲折的

【注】对应"资本主义必然灭亡、社会主义必然胜利"——这是否定之否定规律在社会形态更替中的体现。

4.3 五对范畴

4.3.1 原因与结果

因果联系必须同时满足: ①引起与被引起; ②前后相继。

辩证关系: 相互依存(无"无果之因"/无"无因之果"); 相互转化; 复杂多样(一因多果/同因异果/一果多因/异因同果/多因多果)。

易错 "有其因必有其果" ❌ / "有原因必有结果" ✅

4.3.2 必然与偶然

必然: 事物联系和发展中一定要发生、确定不移的趋势。 偶然: 并非确定发生的、可以出现也可以不出现的不确定趋势。

辩证关系: 必然通过偶然表现; 偶然受必然支配; 相互转化(基因变异 → 新物种 = 偶然转化为必然; 返祖现象 = 必然转化为偶然)。

【分析题考点】 "小概率事件并非零概率事件" → 必然与偶然的辩证关系: 必然通过偶然表现出来。

4.3.3 现实与可能

现实: 当下的客观存在, 标志着事物的当前状况。 可能: 包含在事物中、预示事物发展前途的种种趋势, 是潜在的尚未实现的东西。

易错 "只要有可能, 一定要努力变成现实" ❌(不是所有可能都应该转化为现实) / "努力把不可能变成现实" ❌

4.3.4 现象与本质

现象 本质
特征 个别的、具体的 一般的、普遍的
变化 多变易逝的 相对稳定的
位置 表面的、外显的 深藏于事物的内部
把握方式 感官直接感知 只有通过理性思维才能把握

本质决定现象, 现象表现本质。

【高频易错】假象 vs 错觉: 假象是客观现象(从反面歪曲表现本质); 错觉是主观认识(错误的感觉)。假象≠错觉!

4.3.5 内容与形式

内容: 构成事物一切要素的总和。形式: 内容诸要素相互结合的结构和表现方式。

辩证关系: 相互依赖、不可分割; 内容决定形式, 形式反作用于内容; 内容和形式的矛盾贯穿事物发展过程始终(从基本适合到基本不适合再到新的基本适合)。

4.4 辩证思维方法

  • 归纳与演绎(一般与个别)
  • 分析与综合(整体与部分)
  • 抽象与具体(理解难点)
  • 逻辑与历史(可命题点): 历史是逻辑的基础, 逻辑是"修正过"的历史; "人体解剖对于猴体解剖是一把钥匙"(从后思索法) —— 对历史的认识从事后开始

五、认识论: 实践与真理

5.1 实践观

必考实践的本质: 实践是人类能动地改造世界的社会性的物质活动。

为什么实践高于(理论)认识? 因为实践具有直接现实性——能够引起客观世界的某种变化, 把人脑中观念的存在变为现实的存在, 给人们提供现实的成果。这是实践的根本特征, 也是实践高于理论(认识)的品格。

实践的三大基本特征: ①客观实在性(主体/客体/中介都是可感知的); ②自觉能动性(有意识、有目的的活动); ③社会历史性(受社会历史条件的制约)。

实践的基本结构: 实践主体(具有主体能力的人) → 实践中介(工具系统+语言符号系统) → 实践客体(实践所指向的对象)

主体客体化 vs 客体主体化: 实践过程中, 主体的本质力量转化为对象物的存在形式 = 主体客体化; 客体的属性/规律转化为主体的本质力量 = 客体主体化。

虚拟实践: 伴随信息化和网络化发展而产生的, 通过数字化中介系统在虚拟空间进行的双向对象化活动。是社会实践的派生形式, 只具有相对独立性。

5.2 实践与认识的辩证关系

5.2.1 实践决定认识

【必考 · 分析题】实践决定认识的四个方面:

  1. 认识来源: 实践产生了认识的需要; 实践为认识的形成提供了可能; 主体加工客体信息的思维模式也来源于实践
  2. 认识发展动力: 实践提出新课题; 实践提供经验材料和物质手段; 实践锻炼和提高主体的认识能力
  3. 认识目的: 认识活动的目的在于更好地改造客体、更有效地指导实践
  4. 检验标准: 实践是检验认识真理性的唯一标准

5.2.2 认识反作用于实践

正确认识指导实践达到预期效果; 错误认识误导实践产生消极作用。理论是实践的先导(科学理论可以走在实践前头, 预见未来, 推动创新)。

【易错判断】

  • "理论是实践的先导" ✅
  • "实践是认识的先导" ❌(理论才是先导)
  • "实践高于认识" ✅(实践具有直接现实性)
  • "认识总是滞后于实践" ❌(认识可以走在实践前头)

5.3 认识的本质: 主体在实践基础上对客体的能动反映

不同派系对认识本质的回答:

派系 认识路线 观点
唯心主义先验论 从思想和感觉到物 认识是先于物质/实践经验的东西
旧唯物主义直观反映论 从物到感觉和思想 消极/被动/一次性/照镜子式反映(缺陷: 离开实践、不了解辩证法)
辩证唯物主义能动反映论 从物到感觉和思想 把实践引入认识论 + 把辩证法应用于反映论

5.4 认识运动的基本规律: "五个两"

5.4.1 两阶段: 感性认识与理性认识

感性认识 理性认识
内涵 感官直接感受的事物现象、外部联系、各个方面 借助抽象思维达到的本质、全体、内部联系、规律性
形式 感觉 → 知觉 → 表象 概念 → 判断 → 推理
特点 直接性、具体性 间接性、抽象性

辩证关系: ①理性认识依赖于感性认识(认识论的唯物论); ②感性认识有待于发展和深化为理性认识(认识论的辩证法); ③两者相互渗透、相互包含; ④统一的基础是实践。

"感觉到的东西不能立刻理解它, 只有理解了的东西才能更深刻地感觉它" (毛泽东) → 感性认识必须上升到理性认识

5.4.2 两飞跃

第一次飞跃(实践 → 认识): 从感性认识上升到理性认识。条件: ①获取十分丰富和合乎实际的感性材料; ②"去粗取精、去伪存真、由此及彼、由表及里"的加工制作。

第二次飞跃(认识 → 实践): 理性认识回到实践中去。更为重要的一次飞跃, 因为: ①认识世界的目的是改造世界; ②认识的真理性只有在实践中才能得到检验和发展。

5.4.3 两因素: 理性因素与非理性因素

理性因素 非理性因素
内涵 理性直观、理性思维等能力 狭义: 情感、意志; 广义: 联想/想象/直觉/灵感/顿悟
作用 指导、解释、预见 驱动/动力、诱导、激活/激发、控制/调节

辩证关系: 理性因素起主导作用, 非理性因素起重要作用, 非理性因素要受理性因素的制约。

5.4.4 两特性: 反复性与无限性

反复性: 对一个复杂事物的认识往往要经过由感性到理性、再由理性到实践的多次反复才能完成。原因: 客观方面——事物本质的暴露有一个过程; 主观方面——人的认识能力有一个提高过程。

无限性: 人类认识是永无止境、无限发展的——"实践、认识、再实践、再认识"的无限循环。

5.4.5 两统一: 历史的、具体的

具体的: 主观认识要同一定时间、地点、条件下的客观实践相符合。 历史的: 主观认识要同特定历史发展阶段的客观实践相适应。

5.5 真理观

必考真理: 对客观事物及其规律的正确反映。

5.5.1 真理的三大特性

1. 客观性: 内容客观 + 标准客观。内容客观, 形式主观。

易错 "有用即真理"(实用主义) ❌ / "多数人承认就是真理"(马赫主义) ❌ —— 这都是主观真理论。

2. 一元性: 同一条件下对特定客体的真理性认识只有一个, 不可能有多个。认识是多元的, 真理是一元的。

3. 绝对性和相对性:

真理的绝对性 真理的相对性
主客观统一的确定性 一定条件下的正确认识
发展的无限性 正确认识是有限度的、不完善的

错误观点: 绝对主义(把"里程碑"当"终点站", 如"马克思主义是一成不变的真理") vs 相对主义(借口发展否认真理客观性, 如"马克思主义过时论")

5.5.2 真理与谬误的辩证关系

辩证关系: ①相互依存(没有真理无所谓谬误, 反之亦然); ②相互贯通(真理中含错误的因素/方面, 谬误中隐藏真理的成分/萌芽); ③相互转化(超出一定范围, 真理变谬误, 谬误变真理)。

【分析题考点】 "这个世界上没有真正的错误, 只有被忽略的智慧" / 梅兰芳"把险些造成舞台事故的错误变为成功的经典之作" → 从认识论角度: 真理与谬误的转化; 从辩证法角度: 矛盾的同一性(矛盾双方在一定条件下相互转化)。

5.5.3 实践是检验真理的唯一标准

为什么实践是唯一标准?

  • 从真理本性看: 真理的本性在于主观和客观相符合。检验真理就是检验主观认识是否与客观实际相符合。检验标准既不能是主观认识本身, 也不能是客观事物——必须是能把主观与客观联系和沟通起来的东西。
  • 从实践特点看: 实践具有直接现实性——能把主观的东西变为客观的东西, 使认识和预想与客观结果进行比较。

实践标准的确定性与不确定性:

确定性(绝对性) 不确定性(相对性)
实践是唯一标准, 此外再无别的标准 一定历史阶段的具体实践有局限性
凡经实践证实的认识都具有不可推翻的性质 实践检验真理是一个过程, 不是一次完成的
实践能够检验一切认识(当前不能的, 最终也会被以后的实践裁决) 已被检验过的真理还要继续经受实践的检验

5.6 价值与价值评价

必考价值: 在实践基础上形成的主体和客体之间的意义关系, 是客体对个人/群体/社会的积极意义 = 主体需要 + 客体属性。

价值的四大特性: ①主体性(相对高频); ②客观性; ③多维性; ④社会历史性。

价值评价的特点:

  • 评价以主客体的价值关系为认识对象
  • 评价结果与评价主体有直接联系(依主体特点而转移)
  • 评价结果的正确与否依赖于对客体状况和主体需要的认识
  • 价值评价有科学和非科学之别

5.7 真理与价值的辩证统一

真理尺度(客观尺度/外在尺度) 价值尺度(主体尺度/内在尺度)
实践中必须遵循正确反映客观规律的真理 实践中按照自己的尺度和需要去认识/改造世界

任何成功的实践都是真理尺度和价值尺度的统一:

  • 价值尺度必须以真理为前提(没有真理指引, 价值就偏离正确轨道)
  • 人类自身需要推动人们不断发现新的真理(没有价值追求, 真理失去主体意义)
  • 二者的统一是具体的和历史的, 随实践发展而不断发展

六、唯物史观: 人类社会及其发展规律

6.1 社会结构论

6.1.1 社会存在与社会意识

必考社会存在 = 自然地理环境 + 人口因素 + 物质生产方式

要素 作用
自然地理环境 人类社会生存和发展的永恒的、必要的条件; 重要因素但非决定因素(反对"地理环境决定论")
人口因素 重要的社会物质生活条件; 加速/延缓作用(反对"人口决定论")
物质生产方式 决定作用: ①人类其他一切活动的首要前提; ②决定社会的结构/性质/面貌; ③决定社会形态从低级向高级的更替

高频社会存在决定社会意识, 社会意识具有相对独立性:

  • 第一, 社会存在是社会意识内容的客观来源, 社会意识是社会物质生活过程及其条件的主观反映
  • 第二, 社会意识具有相对独立性: ①不完全同步性和不平衡性; ②内部各种形式之间相互影响且各自具有历史继承性; ③对社会存在具有能动的反作用(最突出表现)

6.1.2 生产力与生产关系

必考生产力 = 劳动资料 + 劳动对象 + 劳动者 + 科学技术(重要因素/渗透因素)

生产关系: 人们在物质生产过程中形成的不以人的意志为转移的经济关系, 是社会关系中最基本的关系。

生产关系的内容: ①生产资料所有制关系(最基本的, 是区分不同生产方式/判定社会经济结构性质的客观依据); ②生产中人与人的关系; ③产品分配关系

生产力与生产关系的辩证关系:

  1. 生产力决定生产关系: 生产力状况决定生产关系的性质("手推磨产生封建主社会, 蒸汽磨产生工业资本家社会"); 生产力的发展决定生产关系的变革
  2. 生产关系反作用于生产力: 适合 → 推动; 不适合 → 阻碍

6.1.3 经济基础与上层建筑

必考经济基础: 由社会一定发展阶段的生产力所决定的生产关系的总和(占统治地位的生产关系)。

上层建筑: 观念上层建筑(意识形态: 政治法律思想/道德/哲学/艺术/宗教等) + 政治上层建筑(国家政权/政治法律制度/军队/警察等)

经济基础与上层建筑的辩证关系:

  1. 经济基础决定上层建筑: 产生、性质、变化发展都由经济基础决定
  2. 上层建筑反作用于经济基础: 促进或阻碍

【高频易错】 "当上层建筑适合经济基础时, 对社会的发展起推动作用" ❌ —— 上层建筑反作用的性质取决于它所服务的经济基础是否有利于生产力发展。真正推动社会发展的条件是: 上层建筑为适合生产力发展的经济基础服务。

6.1.4 社会形态更替

社会形态: 经济基础(骨骼系统) + 上层建筑(血肉系统)

更替特点:

  1. 统一性和多样性: 统一在社会形态依次演进大方向; 多样性在具体道路/形式
  2. 必然性和选择性: 合规律性与合目的性统一
  3. 前进性和曲折性: 前进性(扬弃的过程) + 曲折性(反复/停滞/倒退)

6.2 社会动力论

动力 地位
社会基本矛盾(生产力-生产关系, 经济基础-上层建筑) 历史发展的根本动力
阶级斗争 阶级社会发展的直接动力
革命 阶级斗争的最高形式
改革 推动社会发展的重要动力
科学技术 推动经济和社会发展的强大杠杆 【分析题可考】
文化 推动社会发展的重要力量

【分析题】科学技术的社会作用(双刃剑):

  • 积极作用: 促进经济发展造福人类, 标志着改造自然能力的增强
  • 消极作用: 对自然规律认识不够/缺乏控制手段; 与一定社会制度有关
  • 正确认识和运用: 首要的是有合理的社会制度保障正确运用, 让科技为人类造福

6.3 社会主体论

必考现实的人: 处在现实的、可以通过经验观察到的、在一定条件下进行的发展过程中的人; 基于自身需要和社会需要而从事一定实践活动的、处于一定社会关系中的、具有能动性的人。

人的本质: "人的本质不是单个人所固有的抽象物, 在其现实性上, 它是一切社会关系的总和。"(马克思)

  • 人的本质属性是社会属性(不是自然属性)
  • 人的本质是具体的、历史的(不是抽象的、永恒不变的)

【高频易错】

  • "人人创造历史" ❌
  • "人人创造自己的历史" ✅
  • "人民群众创造历史" ✅
  • "历史是无数个追求自己目的的人的活动的合力" ✅

人民群众在创造历史过程中的决定作用(受社会历史条件制约):

  • 经济条件: 生产力发展水平(首要的、决定性的影响)
  • 政治条件: 政治制度和民主制度(直接影响)
  • 精神条件: 科学文化、思想文化传统和意识形态(重要因素)

历史人物的作用: 可以加速或延缓历史任务的解决, 但不能决定历史发展的基本趋势; 要受社会历史条件的制约和人民群众及其实践活动的制约。

七、政治经济学

7.1 劳动价值论

7.1.1 商品经济

必考自然经济: 自给自足, 生产为了直接满足需要而非交换。

商品经济: 以交换为目的而进行生产的经济形式。

产生的两个历史条件: ①社会分工的出现; ②生产资料和劳动产品属于不同的所有者。

两个阶段:

  • 简单商品经济: 私有制 + 个体劳动, 为买而卖(W-G-W)
  • 资本主义商品经济: 私有制 + 雇佣劳动, 为卖而买, 追求利润(G-W-G')

7.1.2 商品二因素

必考使用价值: 商品能满足人们某种需要的属性(有用性)。自然属性, 反映人与自然的关系。构成社会财富的物质内容。交换价值的物质承担者。

价值: 凝结在商品中的无差别的一般人类劳动。社会属性, 反映人与人之间的关系。

交换价值: 一种使用价值同另一种使用价值交换的量的关系或比例。价值是交换价值的基础, 交换价值是价值的表现形式。

使用价值与价值的对立统一:

  • 对立性(不可兼得): 要获得价值必须放弃使用价值; 要得到使用价值就不能得到价值
  • 统一性(同时具备): 作为商品, 必须同时具有使用价值和价值

易错 四类物品:

  • 有使用价值 + 有价值 = 商品
  • 无使用价值 + 无价值 = 废品
  • 有使用价值 + 无价值 = 有用的非劳动产品(空气/阳光)
  • 无使用价值 + 有价值 = 不存在

7.1.3 劳动二重性

必考劳动二重性决定商品二因素:

  • 具体劳动 → 创造使用价值(转移生产资料的价值)
  • 抽象劳动 → 创造价值(创造新价值)

劳动二重性是理解政治经济学的枢纽。

7.1.4 商品价值量

社会必要劳动时间决定商品价值量。

情景 单位商品价值量 单位时间产量 商品价值总量
社会劳动生产率提高 减少 增加 不变
个别劳动生产率提高 不变 增加 增加

简单劳动与复杂劳动: 复杂劳动 = 自乘的/多倍的简单劳动; 在相同劳动时间里, 复杂劳动创造的价值大于简单劳动创造的价值。

7.1.5 货币

必考货币的五种职能:

职能 内容
价值尺度 衡量商品价值量大小(只需观念上的货币)
流通手段 充当商品交换媒介(必须是现实的货币)
贮藏手段 退出流通领域当作财富贮藏(必须是足值的金属货币)
支付手段 清偿债务(延期支付)
世界货币 世界市场上购买/支付/财富代表

7.1.6 价值规律

必考内容: ①商品价值量由生产商品的社会必要劳动时间决定; ②以价值量为基础, 按照等价交换原则进行。

表现形式: 商品的价格围绕价值自发波动(供不应求→价格高于价值; 供大于求→价格低于价值)。长期看, 价格与价值一致。

【注】 价值规律是商品经济的基本规律, 既支配生产又支配交换。

7.1.7 以私有制为基础的商品经济的基本矛盾

必考私人劳动 vs 社会劳动 是商品经济的基本矛盾。

  • 社会分工 → 劳动具有社会性质(社会劳动)
  • 生产资料私有制 → 劳动具有私人性质(私人劳动)

为什么是基本矛盾? 它决定着商品经济的本质及其发展过程; 是商品经济其他一切矛盾的基础; 决定着商品生产者的命运。

【注】商品经济基本矛盾(私人劳动与社会劳动) --发展--> 资本主义基本矛盾(生产社会化与生产资料资本主义私人占有)

7.1.8 深化对马克思劳动价值论的认识

科学技术本身不能创造价值, 但科学技术在生产中的应用有利于劳动生产率的提高。科学技术为人所掌握, 从而提高劳动效率, 创造出更多的使用价值和价值。

7.2 剩余价值论

7.2.1 劳动力成为商品

必考劳动力成为商品的两个基本条件: ①劳动者是自由人(能支配自己的劳动力); ②劳动者自由得一无所有(丧失一切生产资料)。

劳动力商品的价值: 维持劳动者本人生存所必需的生活资料的价值 + 维持劳动者家属生存所必需的生活资料的价值 + 劳动者的教育和训练费用。

劳动力商品的使用价值: 劳动。劳动创造的价值 > 劳动力自身的价值, 差额 = 剩余价值。这就是货币转化为资本的关键。

7.2.2 剩余价值的生产过程

必考劳动二重性与剩余价值:

  • 具体劳动 → 转移生产资料的价值(c)
  • 抽象劳动 → 创造新价值(劳动力价值v + 剩余价值m)
资本类型 内容 在剩余价值生产中的作用
不变资本(c) 购买生产资料(劳动资料+劳动对象) 转移价值, 不创造新价值
可变资本(v) 购买劳动力 创造新价值, 是剩余价值的源泉

剩余价值率 m' = m/v = 剩余劳动时间/必要劳动时间

绝对剩余价值: 必要劳动时间不变, 延长总工作日 → m'提高 相对剩余价值: 总工作日不变, 缩短必要劳动时间 → m'提高

必考剩余价值是利润的本质, 利润是剩余价值的转化形式。 当剩余价值转化为利润时, 剩余价值与可变资本的关系被掩盖了。

7.2.3 资本积累与资本有机构成

必考资本有机构成: 由资本技术构成决定并反映技术构成变化的资本价值构成, 用 c:v 表示。

概念 含义
资本技术构成 生产资料与劳动力的比例(由技术水平决定)
资本价值构成 不变资本与可变资本的比例(c:v)
资本有机构成 由技术构成决定并反映技术构成变化的价值构成

在资本主义生产过程中, 资本有机构成呈现不断提高趋势, 这是由资本无限追逐剩余价值的本性决定的。

7.2.4 资本的循环与周转

产业资本循环三阶段: 购买阶段(货币资本) → 生产阶段(生产资本) → 售卖阶段(商品资本)

两个条件: 空间上并存 + 时间上继起

固定资本 vs 流动资本:

固定资本 流动资本
形式 厂房/机器设备等劳动资料 原料/燃料/辅助材料 + 劳动力
价值转移 按损耗程度逐渐转移 一次性全部转移(或由新价值补偿)

【注】不变资本≠固定资本 / 可变资本≠流动资本: 不变资本包含固定资本(劳动资料)和流动资本中的劳动对象; 可变资本(劳动力)属于流动资本。

7.2.5 平均利润与生产价格

【必考 · 难点】三次转化:

  1. 剩余价值 → 利润: m转化为p, m'≠p'(利润率 < 剩余价值率)
  2. 利润 → 平均利润: 部门间竞争使利润率趋于平均化, 按等量资本获得等量利润的原则瓜分剩余价值
  3. 商品价值 → 生产价格: 生产价格 = 成本价格(c+v) + 平均利润

获得平均利润的资本: 产业资本、农业资本、商业资本、银行资本。借贷资本获得利息(不是平均利润)。

7.2.6 资本主义经济危机

必考本质特征: 生产相对过剩(不是绝对过剩)。 根本原因: 资本主义基本矛盾(生产社会化与生产资料资本主义私人占有)。

四个阶段: 危机 → 萧条 → 复苏 → 高涨

八、科学社会主义

8.1 社会主义发展

【选择题为主】 资本主义发展两阶段: 自由竞争资本主义 → 垄断资本主义(包括私人垄断资本主义和国家垄断资本主义)。

垄断: 少数大企业为获得高额利润, 通过协议或联合, 对生产/销售/价格进行操纵与控制。

垄断产生的原因: ①生产集中使少数企业联合操纵; ②大企业自然占据垄断地位(中小企业无力对抗, 新企业难以进入); ③避免两败俱伤, 联合实行垄断。

垄断不能消除竞争(反而更加复杂和剧烈): ①垄断没有消除以资本主义私有制为基础的商品经济; ②垄断必须通过竞争来维持; ③任何垄断组织都不能包罗全部社会生产。

8.2 共产主义理想

"两个必然": 资本主义必然灭亡, 社会主义必然胜利。

"两个决不会": 无论哪一个社会形态, 在它所能容纳的全部生产力发挥出来以前, 是决不会灭亡的; 而新的更高的生产关系, 在它的物质存在条件在旧社会的胎胞里成熟以前, 是决不会出现的。

九、易错概念辨析

9.1 物质 ≠ 具体实物

物质是哲学范畴(客观实在), 是对万事万物共性的最高概括。混淆物质和具体实物 = 旧唯物主义的错误。

9.2 矛盾主次 vs 矛盾方面主次

  • 主要矛盾: 在矛盾体系中处于支配地位 → 决定事物的发展方向
  • 矛盾主要方面: 在同一矛盾中处于支配地位 → 决定矛盾的性质
  • 二者都可以转化, 但区分维度不同

9.3 真理绝对性与相对性

  • 绝对主义者把"里程碑"当"终点站"(如认为马克思主义是一成不变的)
  • 相对主义者否认客观真理(如"马克思主义过时论")
  • 正确态度: 真理既是绝对的又是相对的, 需要不断发展

9.4 高频判断"陷阱"集锦

错误观点 正确观点
世界统一于存在 世界统一于物质
人脑是意识的源泉 人脑是意识产生的物质前提, 源泉是客观世界
静止是运动的普遍状态 静止是运动的特殊状态
人人创造历史 人民群众创造历史; 人人创造自己的历史
时空是有限的/无限的(单独说) 具体时空有限, 整个时空无限
实用主义: 有用即真理 真理是客观的, 不因有用而成为真理
科学技术本身能创造价值 科技本身不能创造价值, 科技应用于生产可提高劳动生产率
当上层建筑适合经济基础时一定推动社会发展 取决于经济基础是否有利于生产力发展
认识总是滞后于实践 认识(理论)可以是实践的先导, 走在实践前头

10.3 34题材料分析题答题原理清单
