数三专题

数学 · 理论笔记 · 4 节

覆盖课件 1 份: 数三专题

数三独有考点集中在经济应用——边际分析与弹性分析，属于高等数学导数概念在经济学中的延伸。数一/数二不考此块，但数三几乎必出一道小题或大题的一部分。核心是用导数语言描述经济学中的"边际"与"弹性"概念，本质是变化率与相对变化率的应用题。

一、边际函数

1.1 定义与直觉

必考 设函数 $y = f(x)$ 可导，在经济学中称导函数 $f'(x)$ 为边际函数。

直觉: "边际"就是"多一个单位会怎样"。边际成本就是在当前产量上再多生产一件需要多花多少钱；边际利润就是再多卖一件能多赚多少钱。数学上，这不就是导数吗——精确的变化率。

边际函数值 $f'(x_0)$ 的经济意义：在 $x = x_0$ 处，当自变量 $x$ 增加 1 个单位时，因变量 $y$ 约增加 $f'(x_0)$ 个单位。

常见的边际函数：

经济量 函数 边际函数 含义
总成本 $C(Q)$ $MC = C'(Q)$ 边际成本：多生产1件增加的成本
总收入(收益) $R(Q)$ $MR = R'(Q)$ 边际收益：多卖1件增加的收入
总利润 $L(Q) = R(Q) - C(Q)$ $ML = L'(Q)$ 边际利润：多卖1件增加的利润

1.2 利润最大化的边际条件

重点 利润 $L(Q) = R(Q) - C(Q)$，利润最大化的一阶条件：

$$L'(Q) = R'(Q) - C'(Q) = 0 \quad \Rightarrow \quad MR = MC$$

即边际收益 = 边际成本时，利润取得最大值（还需二阶条件 $L''(Q) < 0$ 确认极大）。

直觉: 当多卖一件赚的钱（MR）正好等于多生产一件花的钱（MC）时，就不该再增产了——再多一件就亏，再少一件没赚够。这是经济学里"边际决策"的核心逻辑。

二、弹性分析

2.1 定义与直觉

必考 在经济学中，把因变量对自变量变化反应的灵敏度称为弹性。设 $y = f(x)$，称

$$\eta = \frac{Ey}{Ex} = \frac{x}{y} \cdot \frac{dy}{dx}$$

为函数 $y = f(x)$ 的弹性函数。

弹性值 $\eta|_{x=x_0}$ 的经济意义：在 $x = x_0$ 处，当自变量增加 1% 时，因变量 $y$ 将增加约 $|\eta|\%$（$\eta > 0$ 时增加，$\eta < 0$ 时减少）。

直觉: 边际是"绝对变化率"（多1单位增多少），弹性是"相对变化率"（多1%增多少%）。比如价格涨1%，需求量降2%，弹性就是-2。弹性是无量纲的——不依赖单位，方便跨商品比较。

2.2 需求价格弹性

高频 设需求量 $Q$ 是价格 $p$ 的函数 $Q = Q(p)$（通常 $Q'(p) < 0$，即涨价需求下降），则需求价格弹性：

$$\eta = \frac{p}{Q} \cdot \frac{dQ}{dp}$$

由于 $dQ/dp < 0$，通常 $\eta < 0$。有时也取绝对值 $\varepsilon = |\eta|$（需求弹性 $\varepsilon > 0$）。

弹性与收益的关系（核心结论）：

弹性 含义 涨价对收益的影响
$|\eta| > 1$ 富有弹性 涨价 → 收益下降
$|\eta| = 1$ 单位弹性 涨价 → 收益不变
$|\eta| < 1$ 缺乏弹性 涨价 → 收益上升

直觉: 弹性大的东西（替代品多），涨价就没生意了；弹性小的东西（刚需），涨一点照样买。

2.3 用弹性表示的定价模型

重点 已知需求弹性 $\varepsilon = |\eta| > 0$，边际成本 $MC$，利润最大化时的最优定价满足：

$$p = \frac{MC}{1 - \frac{1}{\varepsilon}}$$

这是经济学中著名的成本加成定价公式——价格 = 边际成本乘以一个加成系数 $\frac{1}{1-1/\varepsilon}$。

考法视角: 证明题常考这个——从 $L = pQ - C(Q)$ 出发，用链式法则，结合弹性的定义，整理即得。例题3.23就是一个典型的证明+应用。

三、典型例题

3.1 例：边际利润与经济意义

【来源: 数三专题】 设生产某产品的固定成本为 $60000$ 元，可变成本为 $20$ 元/件，价格函数为

$$p = 60 - \frac{Q}{1000}$$

其中 $p$ 是单价（元），$Q$ 是销量（件）。已知产销平衡，求： (1) 该商品的边际利润； (2) 当 $p = 50$ 时的边际利润，并解释其经济意义； (3) 使得利润最大的定价 $P$。

解答过程
Step 1: 建立利润函数 总收入: $R(Q) = p \cdot Q = \left(60 - \frac{Q}{1000}\right)Q = 60Q - \frac{Q^2}{1000}$ 总成本: $C(Q) = 60000 + 20Q$（固定 + 可变） 总利润: $L(Q) = R(Q) - C(Q) = \left(60Q - \frac{Q^2}{1000}\right) - (60000 + 20Q) = 40Q - \frac{Q^2}{1000} - 60000$ Step 2: 边际利润 $$ML = L'(Q) = 40 - \frac{Q}{500}$$ Step 3: $p = 50$ 时的边际利润 当 $p = 50$ 时: $50 = 60 - \frac{Q}{1000} \Rightarrow Q = 10000$ $ML|_{Q=10000} = 40 - \frac{10000}{500} = 40 - 20 = 20$（元/件） 经济意义: 当价格为 50 元/件（即销量为 10000 件）时，销量每多增加 1 件，利润约增加 20 元。 Step 4: 利润最大的定价 令 $L'(Q) = 0$: $40 - \frac{Q}{500} = 0 \Rightarrow Q = 20000$ 代入价格函数: $p = 60 - \frac{20000}{1000} = 60 - 20 = 40$ 验证二阶条件: $L''(Q) = -\frac{1}{500} < 0$，确为极大值。 所以利润最大化的定价为 $P = 40$ 元/件。

3.2 例：弹性定价模型

【来源: 数三专题】 为了实现利润最大化，厂商需要对某商品确定其定价模型。设 $Q$ 为该商品的需求量，$p$ 为价格，$MC$ 为边际成本，$\eta$ 为需求弹性（$\eta > 0$）。

(1) 证明定价模型为 $\displaystyle p = \frac{MC}{1 - \frac{1}{\eta}}$；

(2) 若该商品的成本函数为 $C(Q) = 1600 + Q^2$，需求函数 $Q = 40 - p$，试由 (1) 中的定价模型确定此商品的价格。

解答过程
(1) 证明定价模型 利润 $\pi = pQ - C(Q)$，其中 $Q$ 是 $p$ 的函数。 由链式法则对 $Q$ 求导（把 $p$ 看成 $Q$ 的函数 $p(Q)$）: $$\frac{d\pi}{dQ} = \frac{d(pQ)}{dQ} - \frac{dC}{dQ} = \left(p + Q\frac{dp}{dQ}\right) - MC$$ 利润最大化一阶条件 $\frac{d\pi}{dQ} = 0$: $$p + Q\frac{dp}{dQ} = MC$$ 需求弹性 $\eta = -\frac{p}{Q} \cdot \frac{dQ}{dp}$，所以 $\frac{dQ}{dp} = -\frac{\eta Q}{p}$。 由于 $\frac{dp}{dQ} = \frac{1}{dQ/dp} = -\frac{p}{\eta Q}$，代入: $$p + Q\left(-\frac{p}{\eta Q}\right) = MC$$ $$p - \frac{p}{\eta} = MC$$ $$p\left(1 - \frac{1}{\eta}\right) = MC$$ $$\boxed{p = \frac{MC}{1 - \frac{1}{\eta}}}$$ 证毕。 (2) 应用定价模型 成本函数 $C(Q) = 1600 + Q^2$，边际成本 $MC = C'(Q) = 2Q$。 需求函数 $Q = 40 - p$，即 $p = 40 - Q$，$\frac{dQ}{dp} = -1$。 需求弹性 $\eta = -\frac{p}{Q} \cdot \frac{dQ}{dp} = -\frac{40-Q}{Q} \cdot (-1) = \frac{40-Q}{Q}$。 代入定价模型: $$p = \frac{2Q}{1 - \frac{Q}{40-Q}} = \frac{2Q}{\frac{40-Q-Q}{40-Q}} = \frac{2Q(40-Q)}{40-2Q}$$ 又 $p = 40 - Q$，联立: $$40 - Q = \frac{2Q(40-Q)}{40-2Q}$$ 由于 $Q \neq 40$（否则 $p = 0$），约去 $(40-Q)$: $$1 = \frac{2Q}{40-2Q} \quad \Rightarrow \quad 40 - 2Q = 2Q \quad \Rightarrow \quad 4Q = 40 \quad \Rightarrow \quad Q = 10$$ 代入 $p = 40 - Q = 30$。 答: 最优定价为 $p = 30$。 > 验证: $Q=10$, $MC=20$, $\eta = \frac{30}{10}=3$, $p = \frac{20}{1-1/3} = \frac{20}{2/3} = 30$。自洽。

四、考点小结

考点 频次 核心公式/方法
边际函数的经济意义 必考 $f'(x_0)$: $x$ 增 1 单位时 $y$ 的增量
弹性函数与弹性值 必考 $\eta = \frac{x}{y}\frac{dy}{dx}$, 增 1% 时 $y$ 增 $\eta\%$
利润最大化条件 重点 $MR = MC$，即 $R'(Q) = C'(Q)$
需求弹性 高频 $\eta = \frac{p}{Q}\frac{dQ}{dp}$，$\eta<0$（需求定律）
弹性定价公式 重点 $p = \frac{MC}{1-1/\varepsilon}$

数三 vs 数一/数二: 经济应用（边际+弹性）是数三独有。数一/数二的对应位置是物理应用（速度、加速度、变力做功等）。但弹性本质就是导数在对数坐标下的体现 $\eta = \frac{d(\ln y)}{d(\ln x)}$，理解了这个，会发现它和数学其他分支（如对数求导法）是相通的。
