2.1 向量的概念

定义: n 个数构成的有序数组

定义 由 n 个数构成的有序数组 $(a_1, a_2, \dots, a_n)^{\mathrm{T}}$ 或 $(a_1, a_2, \dots, a_n)$, 称为 n 维列向量 或 n 维行向量。

直觉 列向量竖着写不符合书写习惯、还占位置, 所以约定: 把行向量打个转置来表示列向量, 写 $(a_1,\dots,a_n)^{\mathrm{T}}$ 时它是个列向量——右上角的转置记号别丢注意。向量是"有序"的数组: 顺序不同的数组是两个不同的向量。

内积、模与正交 高频

定义 设 $\boldsymbol{\alpha} = (a_1, \dots, a_n)^{\mathrm{T}}$, $\boldsymbol{\beta} = (b_1, \dots, b_n)^{\mathrm{T}}$, 则内积

$$ \boldsymbol{\alpha}^{\mathrm{T}}\boldsymbol{\beta} = (\boldsymbol{\alpha},\boldsymbol{\beta}) = a_1b_1 + a_2b_2 + \cdots + a_nb_n $$

是一个数(不是向量)。$\boldsymbol{\alpha}^{\mathrm{T}}\boldsymbol{\beta}$ 与 $\boldsymbol{\beta}^{\mathrm{T}}\boldsymbol{\alpha}$ 是同一个东西(对称性)。

内积的性质

性质 内容 备注
(1) 非负 $\boldsymbol{\alpha}^{\mathrm{T}}\boldsymbol{\alpha} = \sum a_i^2 \ge 0$ 平方和
(2) 模 $\lVert \boldsymbol{\alpha} \rVert = \sqrt{\boldsymbol{\alpha}^{\mathrm{T}}\boldsymbol{\alpha}} = \sqrt{\sum a_i^2}$ 长度
(3) 零判定 $\boldsymbol{\alpha}^{\mathrm{T}}\boldsymbol{\alpha} = 0 \iff \boldsymbol{\alpha} = \boldsymbol{0}$ 重点见下
(4) 对称 $\boldsymbol{\alpha}^{\mathrm{T}}\boldsymbol{\beta} = \boldsymbol{\beta}^{\mathrm{T}}\boldsymbol{\alpha}$ 换序不换值

性质 (3) 是老师点名要记住的一条重点: 内积是平方和, 平方和等于零 ⟹ 每个分量都等于零 ⟹ 向量是零向量。第 4 讲解同解方程组时会反复用到这个"平方和 = 0 ⟹ 每个分量为 0"的推理。

正交 $\boldsymbol{\alpha}^{\mathrm{T}}\boldsymbol{\beta} = 0$ 时称 $\boldsymbol{\alpha}$ 与 $\boldsymbol{\beta}$ 正交。两点补充易错:

  • 零向量与任意向量正交(内积恒为 0);
  • 非零向量两两正交 ⟹ 线性无关必考: 设 $\sum c_i\boldsymbol{\beta}_i = \boldsymbol{0}$, 两边左乘 $\boldsymbol{\beta}_j^{\mathrm{T}}$, 除第 j 项外全为 0(正交), 得 $c_j\boldsymbol{\beta}_j^{\mathrm{T}}\boldsymbol{\beta}_j = 0$, 由非零向量模方大于 0 得 $c_j = 0$。前提"非零"不能丢——混进零向量立刻相关(例 2.10 的陷阱)。

2.2 向量组线性相关与线性表出 【必考 · 全讲重心】

定义: "有一组"与"任一组" 易错

线性相关 存在一组不全为零的数 $k_1, \dots, k_s$, 使得

$$ k_1\boldsymbol{\alpha}_1 + k_2\boldsymbol{\alpha}_2 + \cdots + k_s\boldsymbol{\alpha}_s = \boldsymbol{0} $$

线性无关 找不到这样一组不全为零的数——即上式想成立, 只能 $k_1 = \cdots = k_s = 0$。

老师的话: 相关是"存在一种情况", 无关是"一种情况都找不到"——把相关的可能性全部排除掉才是无关。因此做概念辨析题有个小经验易错: 相关的问题里, 带"任意"字样的选项往往错; 无关的问题里, 带"存在/有一组"字样的选项往往错(例 2.1、2.2 全是这个规律)。这只是辅助判断, 不能直接拿来解题。

线性表出: 与相关的区别 注意

定义 若存在 $k_1, \dots, k_s$ 使 $\boldsymbol{\beta} = k_1\boldsymbol{\alpha}_1 + \cdots + k_s\boldsymbol{\alpha}_s$, 称 $\boldsymbol{\beta}$ 可由向量组 $\boldsymbol{\alpha}_1, \dots, \boldsymbol{\alpha}_s$ 线性表出。

与"相关"定义的关键区别: 表出对系数 k 没有"不全为零"的要求(全为零也可以)。于是:

  • 零向量可由任意向量组表出(系数全取 0 即可)——所以表出问题一般只讨论 $\boldsymbol{\beta} \ne \boldsymbol{0}$ 的情况, 零向量没有探讨价值;
  • 相关 ⟺ 存在一个向量可由其余向量线性表出(例 2.1 的结论 C, 必考)——这是连接"相关"与"表出"的桥梁。

判别相关/表出的五大手段 必考

  1. 定义法——最直接, 按定义凑系数
  2. 反证法——老师个人偏爱, 设反面推矛盾
  3. 性质(三大定理, 见下)——形式合适时最快
  4. 秩的语言——判断相关性的"终极武器"
  5. 方程组有解——把向量问题翻译成线性方程组

手段 4、5 的统一语言(矩阵乘法): $\sum k_i\boldsymbol{\alpha}_i$ 写成矩阵乘法

$$ k_1\boldsymbol{\alpha}_1 + \cdots + k_s\boldsymbol{\alpha}_s = (\boldsymbol{\alpha}_1, \dots, \boldsymbol{\alpha}_s)\begin{pmatrix} k_1 \\ \vdots \\ k_s \end{pmatrix} = A\boldsymbol{k} $$

设 $A = (\boldsymbol{\alpha}_1, \dots, \boldsymbol{\alpha}_s)$(s 个列向量), 则:

问题 方程组语言 秩的语言
线性相关 $A\boldsymbol{k} = \boldsymbol{0}$ 有非零解 $r(A) < s$(列不满秩)
线性无关 $A\boldsymbol{k} = \boldsymbol{0}$ 只有零解 $r(A) = s$(列满秩)
$\boldsymbol{\beta}$ 可由 $\boldsymbol{\alpha}_1,\dots,\boldsymbol{\alpha}_s$ 表出 $A\boldsymbol{k} = \boldsymbol{\beta}$ 有解 $r(A) = r(A, \boldsymbol{\beta})$

老师的态度: 定义和性质"形式特别合适"就用(像算极限用等价无穷小), 不合适就从秩、方程组、反证法下手(像用泰勒)——具体问题具体分析, 别拿着一招无脑套。

定理 1: 整体与部分 必考

部分相关, 整体相关; 整体无关, 部分无关。即: 相关向量组加向量仍相关; 无关向量组抽向量仍无关。

口诀: "部分相关整体相关, 整体无关部分无关"。

秩视角理解: 相关 = 列不满秩, 加列仍不满秩; 无关 = 列满秩, 抽列仍列满秩——一句话的事。

易错整体相关, 抽掉一部分后相关与否无法判断!(例 2.3(2)): $(1,0),(0,1),(1,1)$ 相关, 去掉 $(1,1)$ 剩 $(1,0),(0,1)$ 无关; 而 $(1,0),(2,0),(0,1)$ 相关, 去掉 $(0,1)$ 剩 $(1,0),(2,0)$ 仍相关。定理只保证"整体无关 ⟹ 部分无关"这一个方向。

定理 2: 接长与缩短 必考

  • 无关向量组, 每个向量接长(加分量)后仍无关;
  • 相关向量组, 每个向量缩短(减分量)后仍相关。

方程组视角理解: 把向量看成方程的系数行, 接长 = 增加方程 = 增加约束, 原来只有零解, 约束更多仍只有零解; 缩短 = 减少方程 = 解集扩大, 原来有非零解, 解集更大仍有非零解。从"解集随约束单调收缩"看, 这两句是同一件事。

易错反方向都不行: 缩短版相关 ⟹ 接长版相关? 不能保证(例 2.4 ③); 缩短版无关 ⟹ 接长版无关? 也不能保证(加分量可能把向量"掰开")。只有"无关接长"和"相关缩短"两个方向可用。

定理 3: 以少表多, 多的相关 必考

若向量组 $\boldsymbol{\beta}_1, \dots, \boldsymbol{\beta}_t$ 可由 $\boldsymbol{\alpha}_1, \dots, \boldsymbol{\alpha}_s$ 线性表出, 且 $t > s$, 则 $\boldsymbol{\beta}_1, \dots, \boldsymbol{\beta}_t$ 线性相关。

口诀: "以少表多, 多的相关"。直觉: s 个向量张出的空间容不下 t 个无关向量——多出来的必然是"废"的。

证明(反证 + 秩): 设 $\boldsymbol{\beta}$ 组无关 ⟹ $r(\boldsymbol{\beta}_1,\dots,\boldsymbol{\beta}_t) = t$; 能被 $\boldsymbol{\alpha}$ 组表出 ⟹ $r(\boldsymbol{\alpha}_1,\dots,\boldsymbol{\alpha}_s) \ge t$(能表出别人的, 信息量不小); 但向量组的秩超不过向量个数, $r(\boldsymbol{\alpha}_1,\dots,\boldsymbol{\alpha}_s) \le s < t$, 矛盾。

秩的语言: 三个常用不等式 必考

  1. 向量组的秩 ≤ 向量个数("个数 ≥ 秩"——处理"向量个数比较"问题的万能桥梁, 例 2.8 ③④ 全靠它)
  2. 组 I 可由组 II 表出 ⟹ $r(\mathrm{II}) \ge r(\mathrm{I})$——表出方向与秩的大小方向相反
  3. 相关 ⟺ 秩 < 个数; 无关 ⟺ 秩 = 个数

2.3 极大线性无关组

定义: 全体的"代表" 重点

定义 若向量组 $\boldsymbol{\alpha}_1, \dots, \boldsymbol{\alpha}_s$ 中存在 r 个向量 $\boldsymbol{\alpha}_{i_1}, \dots, \boldsymbol{\alpha}_{i_r}$ 线性无关, 且再添加组中任一个向量就变得线性相关, 则称这 r 个向量是原向量组的一个极大线性无关组; 所含向量个数 r 称为向量组的秩, 记 $r(\boldsymbol{\alpha}_1, \dots, \boldsymbol{\alpha}_s)$。

直觉 极大无关组是能"代表"全体向量的班子——组里每个向量都能由它表出, 它自己又保持无关。判定它只需要两条:

  1. 线性无关;
  2. 个数 = 向量组的秩。

秩为 r 时的四个提醒 易错

说法 对错 理由
任意 r 个向量都是极大无关组 错 那 r 个向量可能相关(例 2.11: {α1,α2,α4} 就不行)
任意 r 个线性无关的向量都是极大无关组 对 无关 + 个数够, 自动能表出其余所有向量
多于 r 个向量的向量组一定线性相关 对 秩超不过 r, 满不了秩
r 个向量的向量组一定线性无关 错 得恰好取到无关的那组

求法: 初等行变换 → 行阶梯 高频

原理 初等行变换不改变列向量组的线性相关性——可以在变换后的矩阵上找无关组, 结论对原矩阵照样成立。

为什么 列之间的线性关系由一组系数表达: $k_1\boldsymbol{\alpha}_1 + \cdots + k_s\boldsymbol{\alpha}_s = \boldsymbol{0}$ 是齐次方程组, 初等行变换是同解变换, 系数组原封不动(这一条老师在第 1 讲求极大无关组时埋了伏笔, 本讲结尾才点破)。

步骤

  1. 把向量按列拼成矩阵
  2. 初等行变换化成行阶梯
  3. 含台阶(主元)的列, 对应原矩阵的列构成一个极大无关组; 主元个数 = 秩

注意极大无关组不唯一: 只要取到的列在阶梯里"地位相同"即可(例 2.11: {α1,α2,α3} 与 {α1,α3,α4} 都行, {α1,α2,α4} 不行——后三者在阶梯中相关)。拿不准就算一算对应的子式。

2.4 向量组等价 【必考 · 最难】

定义与三个充要条件

同维向量组 $\{\boldsymbol{\alpha}_1,\dots,\boldsymbol{\alpha}_s\}$ 与 $\{\boldsymbol{\beta}_1,\dots,\boldsymbol{\beta}_t\}$ 等价, 等价于以下任一条:

  1. 相互线性表出: 两个组可以互相表示;
  2. 单方向表出 + 秩相等: 某一个组能表出另一个组, 且 $r(\boldsymbol{\alpha}_1,\dots,\boldsymbol{\alpha}_s) = r(\boldsymbol{\beta}_1,\dots,\boldsymbol{\beta}_t)$——最常用的判据;
  3. 三秩相同: $r(\boldsymbol{\alpha}_1,\dots,\boldsymbol{\alpha}_s) = r(\boldsymbol{\beta}_1,\dots,\boldsymbol{\beta}_t) = r(\boldsymbol{\alpha}_1,\dots,\boldsymbol{\alpha}_s, \boldsymbol{\beta}_1,\dots,\boldsymbol{\beta}_t)$——列向量组把两个组横着拼成一个大矩阵。

注意行向量组等价时, 三秩相同要竖着拼: $r(\boldsymbol{\alpha}_1;\dots;\boldsymbol{\alpha}_s) = r(\boldsymbol{\beta}_1;\dots;\boldsymbol{\beta}_t) = r(\boldsymbol{\alpha}_1;\dots;\boldsymbol{\alpha}_s;\boldsymbol{\beta}_1;\dots;\boldsymbol{\beta}_t)$。横拼竖拼别搞混。

两条提醒

  • 向量组与自己的极大无关组等价(极大无关组能表出全体, 且秩相等——判据 2 直接验证);
  • 该向量组的任意两个极大无关组等价(用"都与原组等价"搭桥)。

两个提问(易错)

  • 等价 + 一个无关 ⟹ 另一个也无关? 否——等价只要求相互表出, 对个数没要求, 可以往组里添"废向量": $\{\boldsymbol{e}_1,\boldsymbol{e}_2\}$ 与 $\{\boldsymbol{e}_1,\boldsymbol{e}_2,\boldsymbol{0}\}$ 等价, 后者相关;
  • 等价 ⟹ 个数相同? 否——同上, 随便添废向量都还等价。

矩阵乘法的分块解读: 线代精髓 必考

设 A 是 m×n 矩阵, B 是 n×s 矩阵, C = AB:

  • 列视角: 对 A、C 按列分块, C 的每一列是 A 的列向量的线性组合($\boldsymbol{c}_j = b_{1j}\boldsymbol{\alpha}_1 + \cdots + b_{nj}\boldsymbol{\alpha}_n$), 即 C 的列可由 A 的列线性表出;
  • 行视角: 对 B、C 按行分块, C 的每一行是 B 的行向量的线性组合, 即 C 的行可由 B 的行线性表出;
  • AB = O 特例: B 的每一列都是齐次方程组 $A\boldsymbol{x} = \boldsymbol{0}$ 的解。

老师的记忆技巧易错: 很多人总记混成"AB 的列可由 B 的列表出"。用特殊记一般: B 可逆时右乘相当于做列变换, AB 的列与 A 的列等价(显然由 A 的表出); 特殊成立, 一般的 B 就至少能推出"由 A 的列表出"。同理 A 可逆时, AB 的行与 B 的行等价。

推论(秩不等式): $r(AB) \le \min\{r(A), r(B)\}$; 能拼在一起时 $r(A, AB) = r(A)$。

初等变换与等价 高频

  • 行变换 ⟺ 左乘可逆阵 ⟹ 行向量组等价, 且不改变列的相关性(求极大无关组的原理);
  • 列变换 ⟺ 右乘可逆阵 ⟹ 列向量组等价, 且不改变行的相关性;
  • 易错行变换后, 非齐次方程组 $A\boldsymbol{x} = \boldsymbol{b}$ 与 $B\boldsymbol{x} = \boldsymbol{b}$ 未必同解(只有齐次方程组同解); 行列式也可能变号(换行)。

向量重要结论总结(讲义总结页) 必考

老师收官时把本讲结论过了一遍(讲义/手稿末尾的「向量重要结论总结」页), 以下条目建议背熟:

AB = C(m×n 乘 n×s)系列

结论 内容
列视角 AB 的列可由 A 的列线性表出 ⟹ $r(AB) \le r(A)$; B 的第 i 列是 $A\boldsymbol{x} = \boldsymbol{c}_i$ 的解(C 按列分块)
行视角 AB 的行可由 B 的行线性表出 ⟹ $r(AB) \le r(B)$
合并 $r(AB) \le \min\{r(A), r(B)\}$; $r(A, AB) = r(A)$(能拼时)
AB = O 特例 B 的列都是 $A\boldsymbol{x} = \boldsymbol{0}$ 的解; B ≠ O ⟹ A 的列线性相关; A ≠ O ⟹ B 的行线性相关; $r(A) + r(B) \le n$(由 $n - r(A) \ge r(B)$ 移项)
可逆特例 B 可逆: AB 的列与 A 的列等价; A 可逆: AB 的行与 B 的行等价

向量组等价: 三条件——相互表出 / 单方向表出 + 秩相等 / 三秩相同(列组横拼、行组竖拼)。

初等变换: 行变换 ⟹ 行向量组等价 + 列相关性不变; 列变换 ⟹ 列向量组等价 + 行相关性不变。

正交: 非零向量两两正交 ⟹ 线性无关; 零向量与任意向量正交、可由任意向量组表出。

秩的另一方面(易漏): $r(A) = r$ 意味着存在 r 阶子式 ≠ 0 且所有 r+1 阶子式 = 0——判"秩等于多少"两半都得查(例 2.4 ① 的坑)。

知识连接

  • 与第 2 讲(矩阵): 分块矩阵的转置(大转加小转)、乘法的行/列分块视角, 本讲是主力工具(例 2.9 用分块转置证 $r(A^{\mathrm{T}}) = r(A)$, 例 2.18 用分块矩阵的秩); "矩阵乘法越乘秩越小"($r(AB) \le \min\{r(A), r(B)\}$)就是本讲表出结论的推论。
  • 与第 4 讲(线性方程组): 相关 ⟺ $A\boldsymbol{x} = \boldsymbol{0}$ 有非零解, 表出 ⟺ 非齐次有解——本讲的秩语言在第 4 讲直接演变成"解的结构"; 老师点名基础好的同学第 4 讲只需听同解问题, 而同解的证明依赖本讲的内积零判定($\boldsymbol{x}^{\mathrm{T}}\boldsymbol{x} = 0 \iff \boldsymbol{x} = \boldsymbol{0}$)与初等变换性质。
  • 与后续(特征值): "非零正交 ⟹ 无关"与"不同特征值的特征向量无关"是同一个证明套路——左乘消灭其它项, 留下自己的项再证系数为零; 无关性是特征向量理论的地基。
  • 本章主线: 判定相关/无关/表出的手段 = 定义、反证、性质、秩、方程组——老师讲这十几道例题刻意每题换一种方法, 目的就是让你在考场上"看形式挑方法"。
