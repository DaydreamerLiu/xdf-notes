## 本讲定位

老师开场第一句就是本讲的灵魂: **"方程组和向量某种意义上是同一个问题的两种表现形式, 它的本质是一回事"**。上一讲(向量)没搞明白的点, 这一讲能找到答案; 这一讲有疑惑的地方, 回去翻向量。他说: "大家一定要学会从向量角度和方程组角度去看待问题, 一定要养成这种意识。"具体说:

- **齐次方程组** $\mathbf{A}\mathbf{x} = \mathbf{0}$ = 列向量组**线性相关/无关**问题——你解出来的这一组解, "不是别的, 就是这个列向量组线性相关的那组系数"
- **非齐次方程组** $\mathbf{A}\mathbf{x} = \mathbf{b}$ = **线性表出**问题——用 $\boldsymbol{\alpha}_1,\dots,\boldsymbol{\alpha}_n$ 去表出 $\boldsymbol{\beta}$, 表出用的那组系数 $k$ 就是方程组的解

三块内容: **3.1 求解**(基本功, 必须熟练) → **3.2 解的性质与解的结构**(选择题最爱考, 非齐次的两条性质是"三颗星"重点) → **3.3 公共解与同解问题**(大家最头疼的部分, 钥匙是**行向量组等价**——"你如果心中有向量这个概念, 学起来会非常轻松")。

## 3.1 线性方程组的求解

### 定义: 同一个问题的两种表现形式

**齐次线性方程组**: 常数项全为 0

$$ \mathbf{A}\mathbf{x} = \mathbf{0} \qquad \iff \qquad x_1\boldsymbol{\alpha}_1 + x_2\boldsymbol{\alpha}_2 + \cdots + x_n\boldsymbol{\alpha}_n = \mathbf{0} $$

**非齐次线性方程组**: $\mathbf{b}$ 不全为 0

$$ \mathbf{A}\mathbf{x} = \mathbf{b} \qquad \iff \qquad x_1\boldsymbol{\alpha}_1 + x_2\boldsymbol{\alpha}_2 + \cdots + x_n\boldsymbol{\alpha}_n = \boldsymbol{\beta} $$

其中 $\boldsymbol{\alpha}_j = (a_{1j}, a_{2j}, \dots, a_{mj})^{\mathrm{T}}$ 是 $\mathbf{A}$ 的第 $j$ 列。

**直觉** 未知数 $x_j$ 就是列向量 $\boldsymbol{\alpha}_j$ 前面的系数。所以"解方程组"和"找线性组合的系数"是同一件事——这就是为什么两个问题的解决方法完全一样。

### 有解条件: 一句话——秩说话 【必考】

**齐次** $\mathbf{A}\mathbf{x} = \mathbf{0}$($n$ 为未知数个数 = $\mathbf{A}$ 的列数):

- $r(\mathbf{A}) = n$(列满秩, $\boldsymbol{\alpha}_1,\dots,\boldsymbol{\alpha}_n$ 线性无关)⟹ 只有**零解**
- $r(\mathbf{A}) = r < n$(列不满秩, 线性相关)⟹ 有**非零解**, 且恰有 $n - r$ 个线性无关解

**非齐次** $\mathbf{A}\mathbf{x} = \mathbf{b}$:

- $r(\mathbf{A}) \neq r(\mathbf{A} \mid \mathbf{b})$ ⟹ **无解**($\boldsymbol{\beta}$ 不能由 $\boldsymbol{\alpha}_1,\dots,\boldsymbol{\alpha}_n$ 线性表出)
- $r(\mathbf{A}) = r(\mathbf{A} \mid \mathbf{b}) = n$ ⟹ **唯一解**
- $r(\mathbf{A}) = r(\mathbf{A} \mid \mathbf{b}) = r < n$ ⟹ **无穷多解**

**直觉与推导**

- 列满秩 ⟹ 找不到不全为零的系数组合 ⟹ 只有零解; 列不满秩 ⟹ 找得到非零系数 ⟹ 非零解。
- 非齐次: 把 $\boldsymbol{\beta}$ 丢进 $\mathbf{A}$ 秩不变 ⟺ $\boldsymbol{\beta}$ 能被表出(找得到系数 $k$ = 有解)。若 $r(\mathbf{A}) = n$ 却有(至少)两个不同解 $\mathbf{x}_1 \ne \mathbf{x}_2$, 则 $\mathbf{A}(\mathbf{x}_1 - \mathbf{x}_2) = \mathbf{0}$ 有非零解, 与列满秩矛盾——所以 $r(\mathbf{A}) = n$ 时必为唯一解【重点】。
- 无穷多解: 通解 = 齐次通解 + 特解, 齐次通解带 $n - r$ 个任意常数, 故解无限多。

**彩蛋(老师补充)** 从方程组角度理解秩不等式: 若 $\mathbf{AB} = \mathbf{O}$, 则 $r(\mathbf{A}) + r(\mathbf{B}) \le n$。把 $\mathbf{B}$ 列分块, $\mathbf{B}$ 的每一列都是 $\mathbf{A}\mathbf{x} = \mathbf{0}$ 的解, 而 $\mathbf{A}\mathbf{x} = \mathbf{0}$ 的线性无关解最多 $n - r(\mathbf{A})$ 个, 所以 $r(\mathbf{B}) = \mathbf{B}$ 的列秩 $\le n - r(\mathbf{A})$, 移项即得【重点】。看到 $\mathbf{AB} = \mathbf{O}$ 就要想到这个双视角: ①列分块: $\mathbf{B}$ 的每列是 $\mathbf{A}\mathbf{x} = \mathbf{0}$ 的解; ②秩不等式(例 3.8 两条都用)。

### 基础解系与通解 【必考】

**基础解系** = $n - r(\mathbf{A})$ 个向量 $\boldsymbol{\xi}_1, \dots, \boldsymbol{\xi}_{n-r}$, 三个关键词缺一不可【易错】:

1. **是解**: 每个向量都是 $\mathbf{A}\mathbf{x} = \mathbf{0}$ 的解;
2. **线性无关**;
3. **个数**满足要求: 恰好 $n - r(\mathbf{A})$ 个(此时"任一解均可由它们线性表出"自动成立)。

**通解**: $\mathbf{x} = k_1\boldsymbol{\xi}_1 + \cdots + k_{n-r}\boldsymbol{\xi}_{n-r}$, 其中 $k_1,\dots,k_{n-r}$ 为**任意常数**。

**易错** 【易错】 通解的常数 $k$ 是任意常数, 但若某题让你求**特征向量**, 必须带 $k \ne 0$(特征向量要求非零)——"很多地方它是有细微差别的, 大家尤其要注意"。

### 求解方法与步骤 【重点】

标准流程(例 3.1 老师借一道简单题完整回顾):

1. **系数矩阵写对**: 缺项补 0(例 3.1 第一行缺 $x_3$, 有人把 $x_4$ 的系数写到 $x_3$ 的位置上, "接下来算啥全错"——第一步错就全错);
2. 初等**行**变换化**行阶梯**(初等行变换是同解变换, 只做行变换, 绝不列变换);
3. 化**行最简**: 阶梯拐角处元素化为 1, 上方元素化为 0——正好构成一个 $r$ 阶单位阵;
4. 按列找出秩为 $r$ 的子矩阵, 剩余列位置的未知数设为**自由变量**;
5. 自由变量分别取 $(1,0,\dots),(0,1,\dots)$ 赋值, 把对应列的**相反数**回填, 得基础解系, 写通解。

**三个提速技巧**(例 3.1 老师给了三种解法, "不一定非要画成行最简"):

- **找单位阵即可**: 化行最简麻烦、常有分数——只要把 pivot 列化成了单位阵, 就可以直接取"自由列相反数"回填, 不必再回写方程组;
- **行阶梯直接回代**: 连单位阵都不用画——从最后一行开始, 每行方程比前面少, 赋一个自由变量就能解出一个, 再往上回代(这是解方程的底层逻辑);
- 形式不同的通解(自由变量选法不同)都对, "这个形式上可能略有差异, 但都没有关系"。

## 3.2 解的性质与解的结构

### 齐次解的性质与结构

**性质** $\boldsymbol{\xi}_1, \dots, \boldsymbol{\xi}_s$ 都是 $\mathbf{A}\mathbf{x} = \mathbf{0}$ 的解 ⟹ 它们的任意线性组合 $\sum k_i \boldsymbol{\xi}_i$ 仍是解(因为 $\mathbf{A}(\sum k_i\boldsymbol{\xi}_i) = \sum k_i \mathbf{A}\boldsymbol{\xi}_i = \mathbf{0}$)。

**结构** 通解 = 基础解系的线性组合(基础解系就是解空间的基)。

### 非齐次解的性质: 两条要背 【必考·三颗星】

设 $\boldsymbol{\eta}_1, \dots, \boldsymbol{\eta}_s$ 是 $\mathbf{A}\mathbf{x} = \mathbf{b}$ 的解, $\boldsymbol{\xi}$ 是导出组 $\mathbf{A}\mathbf{x} = \mathbf{0}$ 的解:

1. **两解之差是齐次解**: $\boldsymbol{\eta}_1 - \boldsymbol{\eta}_2$ 是 $\mathbf{A}\mathbf{x} = \mathbf{0}$ 的解(两边相减, $\mathbf{b}$ 消掉);
2. **系数和定性质**: $k_1\boldsymbol{\eta}_1 + \cdots + k_s\boldsymbol{\eta}_s$:
    - $\sum k_i = 1$ ⟹ 是 $\mathbf{A}\mathbf{x} = \mathbf{b}$ 的解;
    - $\sum k_i = 0$ ⟹ 是 $\mathbf{A}\mathbf{x} = \mathbf{0}$ 的解。
   证明: $\mathbf{A}(\sum k_i\boldsymbol{\eta}_i) = (\sum k_i)\mathbf{b}$——"非常重要, 你务必要把它记住";
3. **解加解**: $\boldsymbol{\eta} + \boldsymbol{\xi}$ 仍是 $\mathbf{A}\mathbf{x} = \mathbf{b}$ 的解。

**结构**: 当非齐次有无穷多解时, 通解 = **特解 + 齐次通解**:

$$ \mathbf{x} = \boldsymbol{\eta}^{*} + k_1\boldsymbol{\xi}_1 + \cdots + k_{n-r}\boldsymbol{\xi}_{n-r} $$

**推论(解的个数上限)** 【高频】 若 $\mathbf{A}\mathbf{x} = \mathbf{0}$ 有 $n - r$ 个线性无关解, 则 $\mathbf{A}\mathbf{x} = \mathbf{b}$ 至多有 $n - r + 1$ 个线性无关解(例 3.12 用它反推秩)。

### 基础解系判断题的套路 【高频】

"某某还能不能作为基础解系?"——三问: **是解吗? 无关吗? 个数对吗?**

- 是解: 新向量是原解的线性组合即可(组合系数和任意);
- 无关: 写成"原基础解系 × 数字矩阵", 算数字矩阵的行列式(满秩 ⟺ 新组无关);
- 个数: $n - r(\mathbf{A})$ 个。

快捷工具(与 3.3 结论 5 呼应): **左乘列满秩矩阵不改变矩阵的秩**——数字矩阵可逆 ⟹ 列满秩, 所以只需算数字矩阵的行列式是否非零(例 3.6)。

## 3.3 方程组的公共解与同解问题

> 老师预告: 这是"大家比较头疼的"部分, 想学好**一定要结合向量组等价**(上一讲最后一个小节务必听完)。

### 公共解: 三种求法

1. **联立求解**: 两个方程组拼在一起解——公共解 = 同时满足两套约束的解;
2. **通解代入**: 求出一个的通解, 代入另一个, 得到系数之间的约束关系, 回代即得公共解(例 3.15 法一);
3. **基础解系联立**: 给出各自的基础解系, 令 $k_1\boldsymbol{\xi}_1 + \cdots + k_s\boldsymbol{\xi}_s = l_1\boldsymbol{\eta}_1 + \cdots + l_t\boldsymbol{\eta}_t$, 解出系数关系, 代回(例 3.15 法二)。

### 同解的充要条件 【必考】

$\mathbf{A}\mathbf{x} = \mathbf{0}$ 与 $\mathbf{B}\mathbf{x} = \mathbf{0}$ 同解 ⟺ 以下三条任意一条:

1. **互含**: $\mathbf{A}\mathbf{x} = \mathbf{0}$ 的解满足 $\mathbf{B}\mathbf{x} = \mathbf{0}$, 且反过来也成立("你是我的解, 我是你的解");
2. **一含 + 秩等**: 能轻易看出一个方程的解满足另一个 ⟹ 再验证 $r(\mathbf{A}) = r(\mathbf{B})$ 即可;
3. **三秩相等**: $r(\mathbf{A}) = r(\mathbf{B}) = r\begin{pmatrix} \mathbf{A} \\ \mathbf{B} \end{pmatrix}$(上下拼接)。

**本质: 行向量组等价** 【重点】 每个行向量就是一个约束关系, 行向量组等价 = 约束关系一样 = 解集一样。"行向量组等价才是同解问题最本质的说法, 比这三条都好用"——解方程做的就是行变换, 行变换是同解变换, 行变换的过程行向量组就等价了。

**直觉(三秩相等为什么行)**: 把 $\mathbf{B}$ 的行偷偷加进 $\mathbf{A}$, 若 $\mathbf{B}$ 的行都能由 $\mathbf{A}$ 的行表出, 加进来是"废约束", 秩不变; 反过来也一样——互相都能表出, 即行向量组等价。注意方向【易错】: **同解 ⟹ 秩相等**(必要), 但**秩相等 ⇏ 同解**。

**非齐次版本**: $\mathbf{A}\mathbf{x} = \boldsymbol{\alpha}$ 与 $\mathbf{B}\mathbf{x} = \boldsymbol{\beta}$ 同解 ⟺ 增广矩阵 $(\mathbf{A} \mid \boldsymbol{\alpha})$ 与 $(\mathbf{B} \mid \boldsymbol{\beta})$ 行向量组等价(三秩相等用增广阵)。

### 常用结论(同解六条)

1. $\mathbf{A}\mathbf{x} = \mathbf{0}$ 与 $\mathbf{B}\mathbf{x} = \mathbf{0}$ 同解 ⟺ $\mathbf{A}, \mathbf{B}$ 行向量组等价;
2. 非齐次同解 ⟺ 增广矩阵行向量组等价;
3. 设 $\mathbf{A}$ 的行向量组可由 $\mathbf{B}$ 的行向量组线性表示 ⟺ $\mathbf{B}\mathbf{x} = \mathbf{0}$ 的解都是 $\mathbf{A}\mathbf{x} = \mathbf{0}$ 的解 ⟺ 存在矩阵 $\mathbf{C}$ 使 $\mathbf{A} = \mathbf{CB}$ ⟹ $r(\mathbf{A}) \le r(\mathbf{B})$【易错】。直觉: 被表出方($\mathbf{A}$)的约束是"衍生约束", 约束少、解集大——**谁的行由谁表出, 谁的解集大**;
4. **$\mathbf{A}^{\mathrm{T}}\mathbf{A}\mathbf{x} = \mathbf{0}$ 与 $\mathbf{A}\mathbf{x} = \mathbf{0}$ 同解** 【必考】: $\mathbf{A}\mathbf{x} = \mathbf{0}$ ⟹ 显然 $\mathbf{A}^{\mathrm{T}}\mathbf{A}\mathbf{x} = \mathbf{0}$; 反过来 $\mathbf{A}^{\mathrm{T}}\mathbf{A}\mathbf{x} = \mathbf{0}$ 左乘 $\mathbf{x}^{\mathrm{T}}$ 得 $(\mathbf{A}\mathbf{x})^{\mathrm{T}}(\mathbf{A}\mathbf{x}) = \lVert \mathbf{A}\mathbf{x} \rVert^2 = 0$, "平方和 = 0 ⟹ 每个分量为 0" ⟹ $\mathbf{A}\mathbf{x} = \mathbf{0}$。推论: $r(\mathbf{A}) = r(\mathbf{A}^{\mathrm{T}}\mathbf{A}) = r(\mathbf{A}\mathbf{A}^{\mathrm{T}}) = r(\mathbf{A}^{\mathrm{T}})$;
5. **$\mathbf{P}$ 列满秩 ⟹ $\mathbf{P}\mathbf{A}\mathbf{x} = \mathbf{0}$ 与 $\mathbf{A}\mathbf{x} = \mathbf{0}$ 同解**: $\mathbf{A}\mathbf{x} = \mathbf{0}$ ⟹ 显然 $\mathbf{P}\mathbf{A}\mathbf{x} = \mathbf{0}$; 反过来把 $\mathbf{A}\mathbf{x}$ 看成列向量, $\mathbf{P}$ 列满秩 ⟹ $\mathbf{P}\mathbf{z} = \mathbf{0}$ 只有零解 ⟹ $\mathbf{A}\mathbf{x} = \mathbf{0}$。推论: **左乘列满秩矩阵不改变矩阵的秩**: $r(\mathbf{P}\mathbf{A}) = r(\mathbf{A})$;
6. 若 $\mathbf{A}\mathbf{x} = \mathbf{0}$ 的解均是 $\mathbf{B}\mathbf{x} = \mathbf{0}$ 的解, 则 $\mathbf{A}\mathbf{x} = \mathbf{0}$ 与 $\begin{pmatrix} \mathbf{A} \\ \mathbf{B} \end{pmatrix}\mathbf{x} = \mathbf{0}$ 同解(把 $\mathbf{B}$ 的行加进来, 解集不变——画圈: 小圈的解全在大圈里, 交集还是小圈)。

### 做题心法: 画圈 【重点】

"$\mathbf{A}\mathbf{x} = \mathbf{0}$ 的解均是 $\mathbf{B}\mathbf{x} = \mathbf{0}$ 的解, 你就画个圈": 谁的解是别人的解 = 谁的解集小。小圈的解都是大圈的解。把"解集包含"翻译成"行向量组的表出方向", 同解题基本不用动笔(例 3.16-3.21 全靠它)。

**矩阵乘法行视角**(例 3.20-3.21 的利器): $\mathbf{AB}$ 的行向量组可由 $\mathbf{B}$ 的行向量组线性表出——所以分块矩阵判同解时, 总能"用右边的块去消左边的块"(行变换)。

## 易错点汇总

- **基础解系三要素缺一不可**: 与基础解系等价的向量组个数没保证; 等秩的向量组连"是解"都没保证(例 3.6);
- **通解常数**: 方程组通解 $k$ 任意, 特征向量 $k \ne 0$;
- **自由变量的选择**: 必须对应"秩为 $r$ 的子矩阵"之外的列(例 3.2);
- **同解 ⟸ 秩相等 ❌**, 同解 ⟹ 秩相等 ✓(例 3.16); **列向量组等价 ⟹ 同解 ❌**——列变换会改变解的结构, 这正是解方程只能行变换的原因(例 3.18);
- **行满秩 ⟹ $\mathbf{A}\mathbf{x} = \mathbf{b}$ 有解 ✓**(增广行向量延长仍无关 / 秩夹逼), 但**行满秩 ⟹ $\mathbf{A}\mathbf{x} = \mathbf{0}$ 有非零解 ❌**——不知道 $m$ 与 $n$ 的大小(例 3.4);
- 唯一解**不带任意常数**("千万不要手贱带个 $k$", 例 3.13);
- 分块矩阵判同解: 只做**行变换**, 列变换会乱(例 3.21 老师强调)。

## 题型与考法

- **具体方程求解**: 直接考(例 3.1, 三种解法都要会), 或考自由变量的选择(例 3.2);
- **有解性判定**: 选择题为主, 核心是"秩与行列数 m, n 的关系"(例 3.3-3.5);
- **解的结构**: 基础解系判断(例 3.6-3.7)、$\mathbf{AB} = \mathbf{O}$ 型(例 3.8)、伴随矩阵型(例 3.9-3.10)、非齐次性质(例 3.11-3.14)——选择题最喜欢考 3.2 这块;
- **公共解**: 大题(例 3.15), 三种求法都要会; 讲义删去了去年数一/数二/数三都考过的公共解真题(与第 3 集重复), 今年直接考的可能不大, 但基本方法必须掌握;
- **同解问题**: 选择题为主(例 3.16-3.21), 分块矩阵行变换是高频道具; 每年都有一道用"同解 ⟺ 行向量组等价"命题的题。

## 知识连接

- **双视角是本讲最大特色**: 向量 ↔ 方程组——齐次 = 相关性问题, 非齐次 = 表出问题, 同解 = 行向量组等价。例 3.19 老师用向量语言(表出)重新解读有解条件, "用向量的语言去表述, 才能做到融会贯通";
- **与前几讲**: $\mathbf{AB} = \mathbf{O}$ ⟹ 秩不等式(矩阵的秩); 三秩相等 ⟷ 向量组等价(第 3 讲); $A_{ij} = a_{ij}$ ⟹ $\mathbf{A}^{*} = \mathbf{A}^{\mathrm{T}}$ ⟹ 正交矩阵(例 3.13, 第 1 讲伴随矩阵 + 第 2 讲正交);
- **与下一讲**: 特征值与特征向量——特征向量就是齐次方程组 $(\mathbf{A} - \lambda\mathbf{E})\mathbf{x} = \mathbf{0}$ 的**非零解**(此时 $k \ne 0$!);
- **内积语言**: $\mathbf{x}^{\mathrm{T}}\mathbf{x} = 0 \iff \mathbf{x} = \mathbf{0}$(第 3 讲内积), 是证 $\mathbf{A}^{\mathrm{T}}\mathbf{A}\mathbf{x} = \mathbf{0}$ 与 $\mathbf{A}\mathbf{x} = \mathbf{0}$ 同解的那"神来之笔"。
