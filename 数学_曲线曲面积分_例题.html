一、三重积分

例 1 计算 $\iiint_\Omega dV$, 其中 $\Omega$ 为 $x+y+z=1$ 与三个坐标平面在第一卦限所围的立体。【0805(1), 题面经视觉核对】

  • 理论三重积分
解答过程
先一后二(投影法): $\iiint_\Omega dV = \iint_D dxdy\int_0^{1-x-y}dz = \iint_D (1-x-y)\,dxdy$, $D: x\ge0,y\ge0,x+y\le1$。$z$ 从平面 $z=0$ 积到 $z=1-x-y$; 投影区域是第一卦限三角形。三重积分的体积 = 区域体积(被积函数 1)。
$= \int_0^1 dx\int_0^{1-x}(1-x-y)\,dy = \int_0^1 \frac{(1-x)^2}{2}\,dx = \frac16$。内层积分 $\int_0^{1-x}(1-x-y)dy = \frac{(1-x)^2}{2}$; 最后 $\frac12\int_0^1(1-x)^2dx = \frac12\cdot\frac13 = \frac16$——四面体体积公式 $\frac13\times$ 底面积 $\times$ 高 的核对。
⭐ 经典: 投影法标准流程: 先定 $z$ 限(上下面), 再投影区域二重积分。

例 2 计算 $\iiint_\Omega z^2\,dV$, 其中 $\Omega$ 为球 $x^2+y^2+z^2\le R^2$ 与球 $x^2+y^2+(z-R)^2\le R^2$ 的交集。【0805(1), 题面按视觉转写定稿; 旧稿误作单球, 已更正】

  • 理论三重积分 碰撞例 3 同为含 $z$ 的三重积分, 本题截面法分段
解答过程
两球交线: 由 $R^2-z^2 = R^2-(z-R)^2$ 得 $z=\frac R2$; 交集 $z\in[0,R]$ 分两段: $z\in[0,\frac R2]$ 截面由球 2(球心 $(0,0,R)$)限制 $x^2+y^2\le R^2-(z-R)^2$, $z\in[\frac R2,R]$ 截面由球 1(球心原点)限制 $x^2+y^2\le R^2-z^2$。两球截面半径平方分别为 $R^2-z^2$ 与 $R^2-(z-R)^2$, 交集截面取较小者, 交界在 $z=R/2$。考点: 截面法适用判据——被积函数只含 $z$ 且截面面积易求; 多曲面围成区域先找交线定分段点。
$\iiint z^2\,dV = \pi\int_0^{R/2} z^2[R^2-(z-R)^2]\,dz + \pi\int_{R/2}^{R} z^2(R^2-z^2)\,dz = \pi\int_0^{R/2}(2Rz^3-z^4)\,dz + \pi\int_{R/2}^{R}(R^2z^2-z^4)\,dz$。$R^2-(z-R)^2 = 2Rz-z^2$。易错: 视觉稿把 $(z-R)^2$ 误读成 $(z+R)^2$, 数学上 $R^2-(z+R)^2$ 在 $z\ge0$ 为负, 不可能是截面。
第一段 $= \pi\left(\frac{R^5}{32}-\frac{R^5}{160}\right) = \frac{12\pi R^5}{480}$; 第二段 $= \pi\left[\left(\frac{R^5}{3}-\frac{R^5}{5}\right)-\left(\frac{R^5}{24}-\frac{R^5}{160}\right)\right] = \frac{47\pi R^5}{480}$; 总 $= \frac{59\pi R^5}{480}$。$\frac{2}{15}=\frac{64}{480}$, $64-17=47$, $47+12=59$。核对: 课件答案 $\frac{59}{480}\pi R^5$ ✓(比单球 $\frac{4\pi R^5}{15}$ 小, 区域缩小所致)。
⭐ 经典: "含 $z$ 且截面已知" → 先二后一; 两曲面所围区域先找交线分段, 逐段套截面面积。

例 3 计算 $\iiint_\Omega (x^2+y^2)\,dV$, 其中 $\Omega$ 由曲线 $y^2=2z$($x=0$ 平面上)绕 $z$ 轴旋转所得旋转抛物面 $x^2+y^2=2z$ 与 $z=2$, $z=8$ 所围。【0805(1), 题面按视觉转写定稿; 旧稿误作锥面 $z=\sqrt{x^2+y^2}$, 已更正】

  • 理论三重积分 碰撞例 2 同为含 $z$ 的三重积分, 本题旋转体用柱面坐标
解答过程
旋转抛物面: $y^2=2z$ 绕 $z$ 轴旋转 → $x^2+y^2=2z$, 即 $z=\frac{x^2+y^2}{2}$; 被 $z=2$ 与 $z=8$ 夹住, $z\in[2,8]$ 截面为圆盘 $x^2+y^2\le 2z$。绕 $z$ 轴旋转时把 $y^2$ 换成 $x^2+y^2$。易错: 旧稿把曲面误读为锥面 $z=\sqrt{x^2+y^2}$(那对应的是旋转直线 $y=z$, 不是本题的旋转抛物线)。
柱面坐标: $\iiint (x^2+y^2)dV = \int_0^{2\pi}d\theta\int_2^8 dz\int_0^{\sqrt{2z}}\rho^3\,d\rho = 2\pi\int_2^8 \frac{(2z)^2}{4}\,dz = 2\pi\int_2^8 z^2\,dz = 2\pi\cdot\frac{8^3-2^3}{3} = 336\pi$。内层 $\int_0^{\sqrt{2z}}\rho^3 d\rho = \frac{(\sqrt{2z})^4}{4} = z^2$; $\frac{512-8}{3}=168$。核对: 课件答案 $336\pi$ ✓。截面法核对: 截面面积 $\pi\cdot2z = 2\pi z$, 截面上 $x^2+y^2$ 的平均值 $=z$(半径平方之半), $\int_2^8 2\pi z\cdot z\,dz$ 同值。
⭐ 经典: 平面曲线绕轴旋转 → 方程中对应变量换成 $x^2+y^2$; 旋转体三重积分用柱面坐标, 先 $r$ 后 $z$。

例 4 计算 $\iiint_\Omega (mx+ly+nz)^2\,dV$, 其中 $\Omega: x^2+y^2+z^2\le a^2$。【0805(1), 题面经 OCR 核对】

  • 理论三重积分(对称性) 碰撞例 5 同为球对称+形心, 一个平方展开、一个平移
解答过程
展开: $(mx+ly+nz)^2 = m^2x^2+l^2y^2+n^2z^2 + 2mlxy + 2mnxz + 2lnyz$。交叉项在球上积分为 0(关于坐标面对称, 奇函数)。球 $x^2+y^2+z^2\le a^2$ 关于三个坐标面都对称, $xy, xz, yz$ 都是关于对应变量的奇函数 → 积分 0。考点: 展开后先消交叉项, 只剩平方项。
$\iiint x^2 dV = \iiint y^2 dV = \iiint z^2 dV = \frac13\iiint(x^2+y^2+z^2)dV = \frac13\int_0^{2\pi}\int_0^\pi\int_0^a \rho^2\cdot\rho^2\sin\varphi\,d\rho d\varphi d\theta = \frac{4\pi a^5}{15}$。轮换对称: 三个平方项积分相等; 球面坐标 $\rho^2\sin\varphi\,dV$ 微元; $\int_0^a\rho^4 d\rho = a^5/5$, 角度积出 $4\pi$。结果 $\frac{4\pi a^5}{15} = \frac{a^2}{5}\cdot\frac{4\pi a^3}{3}$(半径平方均值 $\frac35a^2$ 的核对: $\frac13\cdot\frac{3a^2}{5}\cdot V$)。
原式 $= (m^2+l^2+n^2)\cdot\frac{4\pi a^5}{15}$。三个平方项各 $\frac{4\pi a^5}{15}$, 系数 $m^2+l^2+n^2$ 提出。考点: 展开 + 对称消交叉 + 轮换统一平方项。
⭐ 经典: 球对称积分三连: 展开、交叉项归零、轮换合并平方项。

例 5 计算 $\iiint_\Omega (2x+3y+4z)\,dV$, 其中 $\Omega: (x-1)^2+(y-2)^2+(z-3)^2\le 1$。【0805(1), 题面按视觉转写定稿; 旧稿把一次项系数误作 $2x+4y+8$, 已更正】

  • 理论三重积分(对称性/形心) 碰撞例 4 同为球对称+形心, 一个平方展开、一个平移
解答过程
平移: 令 $X=x-1, Y=y-2, Z=z-3$, 则 $\Omega': X^2+Y^2+Z^2\le 1$, 且 $2x+3y+4z = 2(X+1)+3(Y+2)+4(Z+3) = 2X+3Y+4Z+20$。平移不改变体积; 被积函数在球心展开, 一次项 $2X+3Y+4Z$ 在中心对称球上积分为 0。考点: 球心处展开是处理球上线性函数的固定套路。
原式 $= 20\cdot\frac{4\pi}{3} = \frac{80\pi}{3}$。$\iiint 1\,dV = \frac43\pi\cdot1^3$; 一次项归零后只剩常数 20。形心核对: $(2\bar x+3\bar y+4\bar z)V = (2\cdot1+3\cdot2+4\cdot3)\frac{4\pi}{3} = 20\cdot\frac{4\pi}{3}$。核对: 课件 $\frac{80}{3}\pi$ ✓。
⭐ 经典: 球心展开: 线性项归零, 常数项 × 球体积; 平移换元一步到位。

二、第一型曲线积分

例 6 计算 $\oint_L (2xy+3x^2+4y^2)\,ds$, 其中 $L$ 为椭圆 $\frac{x^2}{4}+\frac{y^2}{3}=1$。【0805(1), 题面按视觉转写定稿; 旧稿把椭圆误作圆 $x^2+y^2=12$, 已更正】

  • 理论第一型曲线积分 碰撞例 7 同为闭合曲线对弧长: 方程代入+形心
解答过程
奇偶性: $2xy$ 关于 $y$ 为奇函数, 椭圆 $L$ 关于 $x$ 轴对称 → $\oint_L 2xy\,ds = 0$。$y\to-y$ 时 $xy\to -xy$, 而 $ds$ 不变, 上下两半抵消。考点: 对弧长积分先看奇偶对称。
在 $L$ 上曲线方程代入: $\frac{x^2}{4}+\frac{y^2}{3}=1$ 两边乘 12 → $3x^2+4y^2=12$ 恒成立, 故 $\oint_L(3x^2+4y^2)ds = 12\oint_L ds = 12a$, 其中 $a$ 为椭圆周长。第一型曲线积分的被积函数只沿曲线取值, 曲线方程可直接代入; 椭圆周长 $a=4\sqrt3 E(e)$ 无初等表达式, 保留 $12a$。考点: 方程代入把二次式化为常数, 积分化为弧长。
原式 $= 0 + 12a$。课件: "$= 12\oint_L ds = 12a$" ✓。易错: 旧稿误把椭圆当圆 $x^2+y^2=12$ 硬凑轮换, 正确做法是整体方程代入。
⭐ 经典: 闭合曲线对弧长积分: 奇偶消项 + 曲线方程代入(整个二次式成常数) + 化为弧长。

例 7 计算 $\oint_L [x^2+(y+1)^2]\,ds$, 其中 $L: x^2+y^2=kx\ (k>0)$。【0805(1), 题面经 OCR 核对】

  • 理论第一型曲线积分
解答过程
圆 $x^2+y^2=kx$ 即 $(x-\frac k2)^2+y^2=\frac{k^2}{4}$, 半径 $R=\frac k2$。配方: 圆过原点, 圆心 $(\frac k2,0)$, 半径 $\frac k2$; 周长 $C = 2\pi R = k\pi$。
$x^2+(y+1)^2 = (x^2+y^2) + 2y + 1 = kx + 2y + 1$。$\oint kx\,ds = k\bar x C = k\cdot\frac k2\cdot k\pi = \frac{k^3\pi}{2}$; $\oint 2y\,ds = 0$(关于 $x$ 轴对称); $\oint 1\,ds = C$。形心: 圆关于 $x$ 轴对称, 质心 $(\frac k2, 0)$, $\oint x\,ds = \bar x C$; $y$ 为奇函数积分 0。考点: 形心公式 $\oint x\,ds = \bar x\cdot$ 弧长 是此类题秒杀技。
原式 $= \frac{k^3\pi}{2} + k\pi = k\pi\left(\frac{k^2}{2}+1\right)$。【AI补全】$kx$ 项 = $\frac{k^3\pi}{2}$, 常数项 $1\cdot C = k\pi$; 两项相加。核对: 课件答案含 $R$ 表达($\oint ds = L$), 以视觉稿为准。
⭐ 经典: 曲线方程代入 + 形心(质心×弧长) + 奇偶归零, 三步秒算。

三、第二型曲线积分与格林公式

例 8 设 $L$ 为折线 $y=1-|x|$ ($-1\le x\le 1$), 从 $(-1,0)$ 到 $(1,0)$, 计算 $\int_L xy\,dx + y^2\,dy$。【0805(2), 题面按视觉转写定稿; 旧稿把曲线误作 $y=|x|$, 起点终点也记反, 已更正】

  • 理论第二型曲线积分
解答过程
分两段: $L_1: y=x+1$ ($x$ 从 $-1\to 0$), $L_2: y=-x+1$ ($x$ 从 $0\to 1$)。$1-|x|$ 在 $x<0$ 为 $1+x$、$x>0$ 为 $1-x$; 折线从 $(-1,0)$ 经顶点 $(0,1)$ 到 $(1,0)$。
$L_1$: $\int_{-1}^{0} [x(x+1) + (x+1)^2\cdot1]\,dx$; $L_2$: $\int_{0}^{1} [x(-x+1) + (-x+1)^2\cdot(-1)]\,dx$。【AI补全】参数化 $y=y(x)$, $dy = y'(x)dx$; $L_1$ 上 $y'=1$, $L_2$ 上 $y'=-1$。考点: 第二型曲线积分参数化后按 $x$ 积分, 下限=起点 $x$ 坐标。
计算: $L_1$: $\int_{-1}^0(x^2+x+x^2+2x+1)dx = \int_{-1}^0(2x^2+3x+1)dx = \frac{2}{3}-\frac32+1 = \frac16$; $L_2$: $\int_0^1(-x^2+x - (x^2-2x+1))dx = \int_0^1(-2x^2+3x-1)dx = -\frac23+\frac32-1 = -\frac16$; 总和 $= \frac16-\frac16 = 0$。两段积分互为相反数。核对: 课件标注两段分别 $\frac16$ 与 $-\frac16$, 和为零 ✓。
⭐ 经典: 折线分段参数化, 每段按 $dy=y'dx$ 代入; 注意起点终点对应的积分限。

例 9 设 $L$ 为椭圆 $4x^2+y^2=8x$, 取逆时针方向, 计算 $\oint_L e^{y^2}\,dx + (x+y^2)\,dy$。【0805(2), 题面按视觉转写定稿; 旧稿把第二项误作 $xy^2\,dy$, 已更正】

  • 理论格林公式 碰撞例 13 同为 $4x^2+y^2$ 型椭圆区域用格林, 本题奇偶消项
解答过程
配方: $4x^2+y^2=8x$ → $4(x-1)^2+y^2=4$, 即 $\frac{(x-1)^2}{1}+\frac{y^2}{4}=1$(中心 $(1,0)$, 半轴 $1,2$)。封闭椭圆直接格林, 无需补线。
格林: $P=e^{y^2}$, $Q=x+y^2$: $\oint_L Pdx+Qdy = \iint_D\left(\frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y}\right)dxdy = \iint_D(1-2ye^{y^2})\,dxdy$。$\partial Q/\partial x = 1$, $\partial P/\partial y = 2ye^{y^2}$(链式)。
$2ye^{y^2}$ 关于 $y$ 为奇函数, 区域 $D$ 关于 $x$ 轴对称 → 积分 0; 原式 $= \iint_D 1\,dxdy = $ 椭圆面积 $= \pi\cdot1\cdot2 = 2\pi$。奇偶消项后只剩面积。核对: 课件 $=2\pi$ ✓(旧稿把 $Q$ 误作 $xy^2$, 才出现需要硬算 $\iint y^2$ 的混乱)。
⭐ 经典: 格林公式把闭曲线积分化二重积分; $e^{y^2}$ 看似吓人, 实为奇函数陷阱, 区域对称直接消。

例 10 计算 $\int_L (2xy-y^4+3)dx + (x^2-4xy^3)dy$, 其中 $L$ 为从 $(1,0)$ 到某点的任意路径。【0805(2), 题面经视觉核对, 终点待核对】

  • 理论积分与路径无关 碰撞例 9 同为 $P,Q$ 型, 本题验证全微分条件
解答过程
检验路径无关条件: $\frac{\partial P}{\partial y} = 2x-4y^3$, $\frac{\partial Q}{\partial x} = 2x-4y^3$, 相等 → 积分与路径无关。$P=2xy-y^4+3$, $Q=x^2-4xy^3$; $\partial_y P = 2x-4y^3 = \partial_x Q$。考点: 全微分条件成立时可选任意路径(通常取折线/直线)。
取折线 $(1,0)\to(x,0)\to(x,y)$: 第一段 $y=0, dy=0$: $\int_1^x 3\,dx = 3(x-1)$; 第二段 $x$ 固定: $\int_0^y (x^2-4xy^3)dy = x^2y - xy^4$。【AI补全】折线法: 先沿 $x$ 轴(只有 $P$ 项, $y=0$ 代入 $P=3$), 再竖直线($dx=0$, 只有 $Q$ 项)。
原式 $= 3(x-1) + x^2y - xy^4$。课件答案 $=5$(若起终点确定), 代入验证。【数值待核对】起终点由题面给定(如 $(1,0)\to(2,1)$: $3+4-2=5$ ✓ 与课件 $=5$ 吻合, 说明终点为 $(2,1)$)。易错: 路径无关时别硬参数化曲线, 折线最省。
⭐ 经典: 全微分条件成立 → 折线积分; 沿 $x$ 轴 + 竖直线两步收口。

例 11 计算 $\int_L \sin 2x\,dx + 2(x^2-1)y\,dy$, 其中 $L$ 是曲线 $y=\sin x$ 上从 $(0,0)$ 到 $(\pi,0)$ 的一段。【0805(2), 题面经视觉核对】

  • 理论第二型曲线积分
解答过程
直接参数化: $y=\sin x$, $dy=\cos x\,dx$, $x$ 从 $0\to\pi$:曲线非闭合, 直接参数化代入; 下限 0 = 起点 $x$ 坐标。
$\int_0^\pi [\sin 2x + 2(x^2-1)\sin x\cos x]\,dx = \int_0^\pi [\sin2x + (x^2-1)\sin 2x]\,dx = \int_0^\pi x^2\sin 2x\,dx$。$\sin2x = 2\sin x\cos x$, 合并同类项; $\sin2x$ 在 $[0,\pi]$ 积分 0(周期对称)。
$\int_0^\pi x^2\sin2x\,dx$: 分部积分两次 $= \left[-\frac{x^2}{2}\cos2x\right]_0^\pi + \int_0^\pi x\cos2x\,dx = -\frac{\pi^2}{2} + \left[\frac{x}{2}\sin2x\right]_0^\pi - \frac12\int_0^\pi\sin2x\,dx = -\frac{\pi^2}{2} + 0 - 0 = -\frac{\pi^2}{2}$。【AI补全】$\int x^2\sin2x\,dx$ 分部: $u=x^2, dv=\sin2x dx$ → $-\frac{x^2}{2}\cos2x + \int x\cos2x\,dx$; 再分部得 $\frac{x}{2}\sin2x-\frac12\int\sin2x dx$。端点代入: $\cos2\pi=1, \cos0=1$ → $-\frac{\pi^2}{2}(1-0)+\frac{\pi}{2}\sin2\pi-0-\frac12\cdot0 = -\frac{\pi^2}{2}$。易错: $\cos2x$ 在端点的值别代错。
⭐ 经典: 正弦曲线直接参数化 + 二倍角合并 + 分部积分两次。

例 12 计算 $\int_L [e^x\sin y - b(x+y)]\,dx + [e^x\cos y - ax]\,dy$, 其中 $L$ 为从 $(2a,0)$ 沿圆弧 $y=\sqrt{2ax-x^2}$ 到 $(0,0)$ 的弧, $a>0$。【0805(2), 题面按视觉转写定稿】

  • 理论格林公式 碰撞例 13 补线/挖洞姊妹题, 同为"闭合化"手段
解答过程
$y=\sqrt{2ax-x^2}$ → $x^2+y^2=2ax$, 即 $(x-a)^2+y^2=a^2$, $L$ 是上半圆弧(从 $(2a,0)$ 到 $(0,0)$); 补线 $L_1$: x 轴上从 $(0,0)$ 到 $(2a,0)$, 使 $L+L_1$ 成逆时针闭曲线。$L_1$ 上 $y=0,\ dy=0$; 半圆面积 $\frac{\pi a^2}{2}$。考点: 缺口曲线 → 补一条简单线段成闭曲线。
$P=e^x\sin y - b(x+y)$, $Q=e^x\cos y - ax$: $\frac{\partial P}{\partial y} = e^x\cos y - b$, $\frac{\partial Q}{\partial x} = e^x\cos y - a$; 格林: $\int_{L+L_1} = \iint_D(b-a)\,d\sigma = (b-a)\frac{\pi a^2}{2}$。两偏导数中 $e^x\cos y$ 相消, 旋度是常数 $b-a$。易错: $P$ 的 $y$ 偏导别漏 $e^x\cos y$ 项(那是 $-b(x+y)$ 中 $-b$ 之外的部分)。
$\int_{L_1} = \int_0^{2a}[e^x\sin 0 - b(x+0)]\,dx = -b\int_0^{2a}x\,dx = -2ba^2$; 原式 $= \int_{L+L_1}-\int_{L_1} = (b-a)\frac{\pi a^2}{2}+2ba^2$。$L_1$ 方向与闭曲线同向, 其积分值为负(被积函数 $-bx$); 减去负值得 $+2ba^2$。核对: 课件 $(b-a)\frac{\pi a^2}{2}+2ba^2$ ✓。
⭐ 经典: 补线法: 缺口曲线 + 简单补线 → 闭曲线用格林, 再减去补线积分; 旋度做差先化简。

例 13 计算 $\oint_L \frac{x\,dy-y\,dx}{4x^2+y^2}$, 其中 $L: (x-1)^2+y^2=R^2$, $R>1$, 取逆时针方向。【0805(2), 题面按视觉转写定稿】

  • 理论格林公式 碰撞例 12 补线/挖洞姊妹题; 例 9 同为 $4x^2+y^2$ 型椭圆区域
解答过程
$P=-\frac{y}{4x^2+y^2}$, $Q=\frac{x}{4x^2+y^2}$: $\frac{\partial Q}{\partial x} = \frac{y^2-4x^2}{(4x^2+y^2)^2}$, $\frac{\partial P}{\partial y} = \frac{y^2-4x^2}{(4x^2+y^2)^2}$, 除原点外恒相等。$R>1$ 保证原点在大圆内部 → 奇点在区域内, 直接格林失效。考点: 旋度为零但有孤立奇点 → 挖洞。
挖洞: 取小椭圆 $L_1: 4x^2+y^2=\varepsilon^2$($\varepsilon$ 足够小, 位于 $L$ 内部), 与 $L$ 同向; $L$ 与 $L_1$ 之间环域上旋度为零 → $\oint_L = \oint_{L_1}$。格林公式在环域: $\oint_L - \oint_{L_1} = \iint 0 = 0$。挖分母的等值线使分母成常数。易错: $L_1$ 是椭圆(半轴 $\frac\varepsilon2,\varepsilon$)不是圆——分母 $4x^2+y^2$ 的等值线是椭圆。
在 $L_1$ 上分母 $=\varepsilon^2$: $\oint_{L_1}\frac{x\,dy-y\,dx}{\varepsilon^2} = \frac1{\varepsilon^2}\oint_{L_1}(x\,dy-y\,dx)$; 又 $\oint_{L_1}x\,dy-y\,dx = \iint 2\,d\sigma = 2\times$椭圆面积 $= 2\cdot\pi\cdot\frac\varepsilon2\cdot\varepsilon = \pi\varepsilon^2$; 原式 $= \frac{\pi\varepsilon^2}{\varepsilon^2} = \pi$。格林: $\oint x\,dy-y\,dx = \iint(1+1)d\sigma = 2S$。核对: 课件取 $\varepsilon=3$: $\frac19\cdot 2\cdot\frac{9\pi}{2} = \pi$ ✓; 结果与 $\varepsilon$ 无关, 挖洞不改变积分值。
⭐ 经典: 挖洞法: 奇点在区域内 → 沿分母等值线挖小椭圆, 环域旋度零 → 化为小椭圆上积分, 分母提常数。

四、第一型曲面积分

例 14 计算 $\iint_\Sigma (xy+yz+zx)\,dS$, 其中 $\Sigma$ 为锥面 $z=\sqrt{x^2+y^2}$ 被圆柱 $x^2+y^2=2ax$ 所截部分, $a>0$。【0805(2), 题面按视觉转写定稿】

  • 理论第一型曲面积分 碰撞例 15 同为第一型曲面积分: 对称性先行
解答过程
对称性: $\Sigma$ 关于 $xz$ 面($y\to-y$)对称, $xy$ 与 $yz$ 都是 $y$ 的奇函数 → 积分 0; 只剩 $\iint_\Sigma xz\,dS$。$dS$ 在对称变换下不变。考点: 曲面积分同样先消奇函数项。
投影法: $z=\sqrt{x^2+y^2}$, $z_x'=\frac{x}{\sqrt{x^2+y^2}}$, $z_y'=\frac{y}{\sqrt{x^2+y^2}}$ → $dS=\sqrt{1+z_x'^2+z_y'^2}\,dxdy = \sqrt2\,dxdy$; 投影 $D: x^2+y^2\le 2ax$ 即 $(x-a)^2+y^2\le a^2$。锥面的 $dS=\sqrt2\,dxdy$ 是常数, 常用结论。
$\iint_\Sigma xz\,dS = \sqrt2\iint_D x\sqrt{x^2+y^2}\,dxdy$。极坐标($D$ 为 $r\le 2a\cos\theta$, $\theta\in[-\frac\pi2,\frac\pi2]$): $= \sqrt2\int_{-\pi/2}^{\pi/2}\cos\theta\,d\theta\int_0^{2a\cos\theta}r^3\,dr = 4\sqrt2\,a^4\int_{-\pi/2}^{\pi/2}\cos^5\theta\,d\theta = 8\sqrt2\,a^4\cdot\frac{8}{15} = \frac{64\sqrt2}{15}a^4$。$x=r\cos\theta$, $z=\sqrt{x^2+y^2}=r$; $\int_0^{2a\cos\theta}r^3dr = \frac{(2a\cos\theta)^4}{4}$; Wallis 公式 $\int_0^{\pi/2}\cos^5\theta\,d\theta = \frac{4\cdot2}{5\cdot3}=\frac8{15}$, 偶函数在对称区间乘 2。核对: 答案 $\frac{64\sqrt2}{15}a^4$ ✓。
⭐ 经典: 曲面积分四步: 对称消项 → $dS$ 投影公式 → 投影区域 → 极坐标求值。

例 15 计算 $\oiint_\Sigma (x+|y|)\,dS$, 其中 $\Sigma: |x|+|y|+|z|=1$(正八面体表面)。【0805(1), 题面按视觉转写定稿】

  • 理论第一型曲面积分 碰撞例 14 同为第一型曲面积分: 对称性先行
解答过程
对称性: $x$ 关于 $yz$ 面为奇函数, $\Sigma$ 关于 $yz$ 面对称 → $\oiint_\Sigma x\,dS = 0$。$x\to-x$ 时 $|x|+|y|+|z|$ 不变, 曲面不变, 正负两半抵消。
轮换对称: $\oiint|x|dS = \oiint|y|dS = \oiint|z|dS$ → $\oiint|y|dS = \frac13\oiint(|x|+|y|+|z|)\,dS = \frac13\oiint_\Sigma 1\,dS$。在 $\Sigma$ 上 $|x|+|y|+|z|=1$ 恒成立 → 曲面方程代入后被积函数化为常数 1。考点: 轮换对称 + 曲面方程代入。
总面积: 正八面体 8 个面, 每面是边长 $\sqrt2$ 的等边三角形(面 $x+y+z=1$ 与坐标轴交于 $(1,0,0),(0,1,0),(0,0,1)$), 面积 $\frac{\sqrt3}{4}(\sqrt2)^2 = \frac{\sqrt3}{2}$ → $S = 8\cdot\frac{\sqrt3}{2} = 4\sqrt3$; 原式 $= \frac13\cdot4\sqrt3 = \frac{4\sqrt3}{3}$。核对: 课件 $\frac{4\sqrt3}{3}$ ✓。
⭐ 经典: 正八面体: 奇偶消 $x$, 轮换均分 $|y|$, 曲面方程代入 → 只算总面积。

知识连接

  • 三重积分两大次序(投影/截面)按"被积函数与截面"选; 旋转体用柱面坐标, 球用球面坐标; 多曲面围成区域先找交线分段
  • 对称性三步(奇偶/轮换/形心)是所有多元积分的共同前奏
  • 第二型曲线积分: 闭合 → 格林(奇点在区域内 → 挖洞); 非闭合 → 补线成闭曲线再减补线积分, 或参数化/路径无关折线
  • 第一型曲面积分: 投影 $dS=\sqrt{1+z_x'^2+z_y'^2}\,dxdy$(锥面 $dS=\sqrt2\,dxdy$), 对称性先行, 曲面方程可代入
